# 系列の書き出しと取り込み

画像の系列(どの画像から何を作ったか)を、原本の画像と Generated の記録ごと ZIP にまとめて持ち出し、別の GAKEI に取り込むための機能。同じインスタンスの別の利用者に渡す、別の PC の GAKEI に移す、といった用途に使う。GAKEI を使っていない納品先に、納品する画像の証跡として渡すこともできる(納品用。4 章)。設計は [ADR-0037](adr/0037-lineage-export-import.md)。

ログイン不要のリンクで見せるだけなら、[共有リンク](sharing.md)を使う。共有リンクは相手の GAKEI には取り込めない。

## 1. 書き出す

1. ビューア(画像を開いた画面)の右上の操作から「系列を書き出す」(箱の形のアイコン)を押す。系列グラフでノードを選んだときのインスペクターにもある。
2. 用途を選ぶ。
   | 用途 | ZIP に入るもの |
   |---|---|
   | GAKEI に取り込む | `manifest.json` と `assets/`。受け取った人が自分の GAKEI に取り込んで、続きの Edit ができる |
   | 納品用 | 上に加えて、ブラウザで開ける記録 `index.html` と説明 `README.txt`(4 章)。GAKEI にも取り込める |
3. 範囲を選ぶ。「この画像と祖先」「系列全体」の計算は共有リンクの「祖先まで」「祖先と子孫」と同じ。「この画像と子孫」は書き出しだけにある(共有リンクには無い)。
   | 範囲 | 含まれる画像 |
   |---|---|
   | この画像と祖先 | その画像と、Edit の元になった画像を親の方向にさかのぼったもの(入力に使ったマスクや参照画像、スケッチの下地も含む) |
   | この画像と子孫 | その画像と、その画像から作った画像(子の方向)。元になった画像は含めない。依頼元から受け取った素材から作った画像を、証跡として渡すときなどに使う |
   | 系列全体 | 祖先と子孫の両方 |

   「この画像と子孫」では、その画像を作った Generated(祖先の側)は入らない。その画像が生成画像でも、`manifest.json` の種類は `generated` のまま、作った Generated の ID と出力の番号は `null` になる。子孫を作った Generated の入力のうち、範囲の外の画像(別の参照画像など)は「含めていない入力」の数だけを書く。
4. 必要なら「実行者の名前を含める」をオンにする(既定はオフ)。
5. 含まれる画像と Generated の数、原本の合計の大きさが出るので、確かめてから「ZIP をダウンロード」を押す。
   「系列をプレビュー」を押すと、選んだ範囲の ZIP に入る画像と Generated だけを、系列グラフと同じ見た目でダイアログの中に描く(範囲を変えると描き直す)。起点の画像は枠で示す。グラフの辺は ZIP の `manifest.json` に書く来歴(Edit の入力、出力、スケッチの下地)と同じで、範囲の外の入力は描かず「範囲の外の入力 N 件は含まれません」と数だけを出す。ノードを押しても移動しない(読み取り専用)。画像が多いときは読める倍率で止めて起点を中央に置くので、全体は「全体を表示」で見る。

ZIP に入るもの:

- `manifest.json`: 形式名と版(`gakei.lineage-export/1`)、書き出した日時、GAKEI の版、範囲、起点の画像、画像の一覧(sha256、種類、寸法、作成日時、どの Generated の何番目の出力か)、Generated の一覧(プロバイダー、モデル、操作、プロンプト、送ったパラメーター(ComfyUI のものは、共有リンクと同じく API キーなど秘密に見える値を `***` に置き換える)、状態、エラー、usage、作成・終了日時、実行者の表示名(「実行者の名前を含める」をオンにしたときだけ。オフのときは `null`)、入力)。
- `assets/{画像の ID}.{拡張子}`: 原本。保存しているバイト列そのまま(ダウンロードした PNG と違い、系列情報は埋め込まない)。

入らないもの:

- 削除した画像、ほかの人の画像(認証モードで見えないもの)。Generated の入力にそれらがあった場合は、ID を出さず「含めていない入力」の数だけを書く。
- タイトル、タグ、グループ、似た画像の検索に使う埋め込み(取り込んだ側で付け直せる)。
- 範囲の画像を生んでいない Generated(失敗して何も出さなかったものなど)。範囲の画像を生んだ Generated は、失敗の記録でも含める。

実行者の表示名(ログインした人の名前)は、「実行者の名前を含める」をオンにしたときだけ入る(既定はオフ。取り込み用・納品用のどちらでも同じ)。オフのときは、`manifest.json` にも `index.html` にも名前を書かない。メールアドレスはどちらでも入らない。名前を含めずに書き出した ZIP を取り込むと、取り込んだ Generated の「元の実行者」は空になる。

## 2. 取り込む

1. ストック(サイドバーの画像のアイコン)の「画像を追加 / ドロップ」の下にある「系列を取り込む」を押し、ZIP を選ぶ。
2. 送信の進み具合が出る。終わると、取り込んだ起点の画像がビューアで開く。

- 取り込んだ画像と Generated の持ち主は、**取り込んだ人** になる。認証モードでは、取り込んだ人にだけ見える。そのまま入力に使って、続きの Edit ができる。
- 同じ ZIP を同じ人がもう一度取り込んでも、何も増えない(前に取り込んだものを開く)。別の人が取り込めば、その人の分が別に作られる。
- 取り込んだ人がすでに同じ内容のアップロード・マスク・スケッチを持っていれば、それを使う。
- 「この画像と子孫」で書き出した ZIP の起点が生成画像のとき、作った Generated は ZIP に入っていないので、起点は **アップロード** として取り込む(作った Generated をこしらえない)。子孫と、子孫を作った Generated は通常どおり取り込まれ、起点から子孫へつながる。
- 取り込みは全部か無しか。ZIP のどこかに問題があれば、何も取り込まずにエラーを出す。

断られる ZIP:

| 理由 | 上限・条件 |
|---|---|
| 大きすぎる | ZIP は 1 GiB まで。画像は 1000 枚まで。1 ファイル 50 MB 未満 |
| 形式が違う | `manifest.json` が無い、形式名・版が `gakei.lineage-export/1` でない、内容の形が違う |
| 書き換えられている | 画像の大きさや sha256 が `manifest.json` と一致しない |
| 不審な ZIP | 圧縮率が極端に高い、同じ名前のファイルが複数ある、暗号化されている |

## 3. 取り込んだ記録の扱い

取り込んだ Generated は、**この GAKEI で実行した記録ではない**。ZIP は誰でも書き換えられるので、中身(プロンプト、パラメーター、元の実行者、日時)は検証していない。画面では次のように区別する。

- Generated の詳細: 「取り込み」のバッジと、元の実行者・元の作成と終了の日時・書き出した GAKEI の版・取り込んだ日時・元の ID を出し、検証していない記録であることを書く。`queued_at` と `finished_at` は取り込んだ日時。
- 系列グラフ: 取り込んだ Generated のノードは破線の枠で、「取り込み」の印が付く。
- 料金: 取り込んだ Generated の usage は記録として残すが、費用(参考)には数えない。MCP の1時間あたりの生成の上限にも数えない。
- この GAKEI に無いプロバイダーやモデルの記録でも取り込める(実行はしない)。「同じ設定で新規作成」は、そのモデルがこの GAKEI で使えるときだけ実行できる。

MCP のツールからの書き出し・取り込み、書き出しへの署名はできない。

## 4. 納品用

GAKEI を使っていない納品先に、主画像(書き出しの起点にした画像)の証跡として系列を渡すための書き出し。主画像は、納品する生成物(範囲は「この画像と祖先」)のことも、生成に使った素材(範囲は「この画像と子孫」か「系列全体」で、子孫が証跡になる)のこともある。「この画像と子孫」では、主画像が系列の図の一番上に来る。主画像が生成画像なら、「作った実行」の欄に、範囲の外であることを書く。

ZIP には、取り込み用と同じ `manifest.json` と `assets/` に加えて、次の2つが入る。

- `index.html`: ZIP を展開して、ブラウザで開く1枚のページ。インターネットにつながっていなくても見られる(外部の CSS・JS・フォントを読まず、画像は同じ ZIP の `assets/` を参照する。JS は使わない)。スマートフォンの幅でも読め、印刷もできる。
  - 冒頭: 主画像、書き出した日時、GAKEI の版、範囲、含まれる画像と生成の実行の数。
  - この ZIP に改ざんの検出や署名が無いことの説明。各画像の sha256 をこのページと `manifest.json` に載せているので、画像ファイルの sha256 を計算して比べれば、画像が差し替わっていないことは確かめられる(ページや `manifest.json` 自体が書き換えられていないことは保証しない)。
  - 系列の図(画像と生成の実行の二部グラフ。上が祖先、主画像は太い金色の枠。枠を押すと詳しい記録に移る)。
  - 画像ごとに: 縮小表示(押すと原本)、ファイル名、sha256、寸法、形式、大きさ、作成日時、種類(アップロード / 生成 / マスク / スケッチ)。
  - 生成の実行ごとに: プロバイダー、モデル、操作(生成 / 編集)、状態、開始・終了日時、入力と出力、プロンプト、パラメーター。ComfyUI のパラメーターの秘密に見える値は `***` に伏せる(取り込み用と同じ)。別の GAKEI から取り込んだ記録は「取り込み・未検証」の印と説明を付け、書き出し元が記録していた元の日時を出す(元の実行者は、名前を含めるときだけ)。
  - 言語は、書き出した人の画面の表示言語(日本語 / 英語)。日時は書き出した人のブラウザのタイムゾーンで書く(分からなければ UTC)。
- `README.txt`: GAKEI の簡単な説明(セルフホストの画像生成ツール。リポジトリ https://github.com/zolgear/gakei)と、ZIP の中身の説明、sha256 の確かめ方。画面の言語にかかわらず、日本語と英語を併記する。

ファイル名は `gakei-delivery-{主画像の ID}-{日付}.zip`(取り込み用は `gakei-lineage-…`)。納品用の ZIP も、そのまま GAKEI に取り込める(`index.html` と `README.txt` は取り込みでは使わない)。

範囲の選び方、含めないもの(削除した画像、ほかの人の画像、範囲の画像を生んでいない Generated、タイトル・タグ・グループ)は取り込み用と同じ。
