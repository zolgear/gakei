# 領域の指示

入力画像の1枚目(主たる入力)の上に四角を描き、四角ごとに名前や「何をするか」を付けて Edit に渡します(ADR-0053)。入力画像の無い生成でも、出力の大きさの白紙の上に四角を描けます。OpenAI では白紙の配置図にして Edit で送り([入力画像の無い生成](#入力画像の無い生成openai))、ComfyUI ではワークフローに差し込みます([ComfyUI](#comfyui))。「この四角の中を赤い帽子にする」「ここに看板を足して OPEN と描く」「この皿を右下へ動かす」のように、場所ごとに別々の指示を付けられます。

四角は場所と大きさの目安です。マスクのような厳密な範囲ではありません。形を細かく決めたいときは、マスクやスケッチを使います。

## 開く

生成のフォームで入力画像を1枚以上入れると、1枚目のチップ(サイドバーの配置ではタイル)に「領域」のボタンが出ます。押すと編集画面が開きます。

- 四角を受けるモデルでだけ出ます。OpenAI(と、確認用の `FAKE_PROVIDER=1`)と、四角の差し込み先を持つ ComfyUI のワークフロー([ComfyUI](#comfyui))です。SD WebUI では出ません。
- 入力画像が無いとき(OpenAI と、四角の差し込み先を持つ ComfyUI のワークフロー)は、入力画像の欄の「スケッチ」の横に「領域」が出ます。押すと白紙の上に描けます。
- 四角を付けると、1枚目に「領域 3」のように数が出ます。押すと続きを編集でき、横の「×」で外せます。

### 土台を選ぶ

入力画像があるときは、編集画面の上の「1枚目の画像 / 白紙」で、四角を描く土台を選べます。

- **1枚目の画像:** 1枚目の上に描きます(既定)。1枚目のどこを変えるかを指示するとき。
- **白紙:** 出力の大きさの白紙に描きます。入力画像は参考に使い、構図だけを四角で指示するとき。四角は1枚目に重ならず、入力の行には白紙の配置図のプレビューが出ます(1枚目に「領域 3」は出ません)。選べる種類は「変える」「足す」だけです。

切り替えても四角は位置を割合のまま移ります。白紙で選べない種類(そのまま残す・消す・動かす)の四角があるときは、切り替えずにそのことを出します。入力画像を足しても外しても土台は変わりません(1枚目の上の四角だけは、1枚目を外して白紙になると白紙に移ります)。

例: キャラクターの画像を入力に入れ、領域を白紙にして、左下に四角を描きます。四角の参照画像にそのキャラクターの画像(入力にある画像)を選び、指示に「この人物が座っている」と書きます。右上にもう1つ四角を描いて「窓」とします。送ると、白紙の配置図がキャラクターの画像の後ろに足され、「2枚目は配置図。ほかの画像は参考に使う」「四角 1 は1枚目の画像を参考にする」という文がプロンプトの後ろに付きます。

## プロンプトを書きながら見る

1枚目に四角か検出の候補があると、プロンプトの欄のすぐ上に「領域と検出の候補」が出ます。1枚目の画像に、四角(番号と色)と検出の候補(点線と名前)を重ねた小さなプレビューと、名前のチップを並べます。

- チップを押すと、その文字をプロンプトのカーソル位置に入れます(直前が空白でなければ、半角の空白を挟みます)。カーソルの位置が分からなければ末尾に入れます。タグの入力のときは、末尾にタグとして足します。
- 「四角 1」などのチップは、四角の番号を書くときに使います。送る文でも同じ呼び方(「四角 1」)で四角を指します。名前のある四角は、「四角 1 左のカバン」のように名前も添えて出します。
- 検出の候補(点線)のチップは、枠が点線で、文字が淡く出ます。**点線の候補は送られません。** 候補のチップを押すと、名前をプロンプトに入れるのと一緒に、その候補を名前の付いた四角(種類は「変える」、指示なし)にします。押した後は「四角 n 名前」のチップに変わり、押し直しても四角は増えません。チップを押すか、「領域」の画面で四角にしたものだけが、四角を描いた画像と文として送られます。
- チップにマウスを重ねる(スマートフォンでは触れる)と、対応する四角や候補を強調します。
- プレビューを押すと大きく見られます。
- 見出しを押すと畳めます。1枚目のチップ・タイルの目のボタンでも出し入れできます。開いているかはブラウザごとに覚えます。
- 出す検出は、「領域」の画面で選んだ検出です(選んでいなければ、いちばん新しい検出)。

## 四角を描く

| 操作 | やり方 |
|---|---|
| 描く | 画像の上の何も無い所をドラッグ(選んでいない四角の内側でも描ける) |
| 選ぶ | 四角の枠か番号を押す。下(広い画面では右)の札からも選べる |
| 動かす | 選んだ四角の内側をドラッグ。矢印キーでも少しずつ動かせる(Shift で大きく) |
| 大きさを変える | 選んだ四角の角と辺のハンドルをドラッグ |
| 外す | 札のごみ箱、ツールバーのごみ箱、または Delete キー |
| 番号を入れ替える | 札の上下の矢印 |
| 元に戻す・やり直す | ボタン、または Ctrl+Z / Shift+Ctrl+Z(Mac は Cmd) |
| 拡大 | ツールバーの拡大・縮小・全体を表示。拡大したときは「画面を動かす」に切り替えるとドラッグで表示を動かせる |

四角は最大 16 個です。四角は画像に対する割合で持つので、拡大しても位置はずれません。タッチの画面でも、指で描いて動かせます。

四角には番号と色が付きます。色は番号の順に赤・青・緑・黄・マゼンタ・水色・オレンジ・紫で、9 個目からは繰り返します。送る画像に描く色と同じです。

## 札

四角ごとに札が出ます。

- **名前(任意):** その四角が何か(「右手の白いカフス」など)。検出の候補から作った四角には、候補の名前が入ります(直せます)。画像の上の四角の横にも出ます。
- **種類:** 変える(既定。白紙では足すが既定)/足す/そのまま残す/消す/動かす。
- **指示(任意):** その四角で何をするか。
- **描く文字:** 看板などに描かせる文字。指示とは分けて、そのまま渡します。
- **参照画像:** その四角に使う画像。入力の画像かストックから選びます。入力に無い画像を選ぶと、送るときに入力の後ろに足します。

四角の定義(位置と名前)と指示は分けて扱います。指示は無くても保存して送れます。

- 指示・描く文字・参照画像のどれも無い「変える」「足す」の四角は、**目印**になります。送る文では、場所と名前だけを示します(「四角 1(赤、右手の白いカフス): 横 10〜30%、縦 20〜40% の範囲。」)。全体のプロンプトから「四角 1 のカフスを金色にする」「白いカフスを外す」のように、番号か名前で指して使います。
- 「そのまま残す」「消す」「動かす」は、指示が無くても種類のとおりに伝えます。
- 保存できないのは、四角の位置が正しくないとき、「動かす」の元の位置が無いとき、文字数の上限(名前 100 文字、指示 2000 文字、描く文字 200 文字)を超えたときだけです。

指示の欄の下には、出している検出の名前のチップが並びます。押すと、指示の欄のカーソル位置に入れます。

画像の上の名前は、近い四角どうしで重なるときは上下にずらして出します。

### 動かす

種類を「動かす」にすると、今の四角が元の位置(点線)になり、横に移す先の四角(実線)ができます。矢印が元の位置から移す先を指します。どちらの四角も動かしたり大きさを変えたりできます。

## 検出

管理者が「領域の検出」を有効にしていると、編集画面に「検出」が出ます。VLM が画像の中の物を探し、四角の候補を点線で出します。候補を押すと四角になり、札ができます(名前には候補の名前が入ります。指示は空のままでも送れます)。

- 「探す物」に言葉を入れると、それに当てはまる物を探します(「カップ」「左の人の服」など)。空なら主な物を一通り(20 個まで)挙げます。
- 1 回に 10 秒以上かかることがあります。待っている間は「取り消す」で止められます。
- 検出の結果は画像ごとに履歴として残ります。編集画面を開くと、いちばん新しい検出の候補が出ます。「検出の履歴」で前の検出に切り替えたり、履歴から消したりできます(消せるのは検出した人と管理者)。「候補を隠す」を選ぶと候補を出しません。検出が無効になっても、履歴は見られます。
- 縦に長い物(鉢植え、風船の紐など)は、下の端が短く出ることがあります。四角を直してから使ってください。
- 物の多い絵では、細かすぎる候補も混じります。使う物だけを選んでください。

検出しなくても、四角は手で描けます。

### 管理者の設定

管理者設定の「領域の検出」で設定します。

- **有効にする:** 既定は無効です。
- **接続先とモデル名:** 「LLM の接続先」から、画像を読める接続先を選びます。既定は OpenAI の `gpt-5.6-luna` です。手元の VLM のサーバーも使えます([手元の VLM](#手元の-vlm))。
  - 接続先が構造化出力(JSON のスキーマ)に対応するなら、スキーマを付けて送ります。対応しないなら、スキーマを付けずに答えの形を指示で示し、応答を緩く読みます(```json の囲み、前後の文、キー名の揺れなどを受けます)。
  - GAKEI は、接続先の「構造化出力」が「自動」のときは、OpenAI の公式の接続先だけを対応とみなします。OpenAI 互換のプロキシ経由で OpenAI のモデルにつなぐときなどは、「LLM の接続先」でその接続先(組み込みの「OpenAI の設定」も含む)を編集し、「構造化出力」を「対応する」にしてください。
  - 応答が答えの形(四角の一覧)でないときは、「見つからない」ではなく検出の失敗として出ます。
  - 使えないときは、この画面に理由(接続先が無い、キーが無い)が出ます。
- **1 時間の上限:** 利用者ごとに、直近 1 時間に検出できる数です。

検出では、画像(長辺を縮めたもの)と指示を接続先へ送り、そのたびに費用がかかります。送る前に Mod の `ai.before_send`(用途 `region_detection`)を呼びます([docs/mods.md](mods.md))。

### 手元の VLM

OpenAI 互換の API を持つ手元の VLM のサーバー(四角を答えられるモデル。Qwen-VL など)で検出できます。

1. 「LLM の接続先」で、そのサーバーの Base URL を登録します。API の形は **Chat Completions** を選びます(サーバーによっては、Responses の口がスキーマを黙って無視します)。
2. サーバーが構造化出力に対応するなら、その接続先の「構造化出力」を「対応する」にします。対応しなくても使えます。
3. 「領域の検出」で、その接続先とモデル名を選びます。

- 座標は 0〜1000 で、x が先の `[x0, y0, x1, y1]` で答えさせます。
- 出力の長さに上限を付けています。同じ候補を繰り返して上限で切れたときは、読めた分だけを使います。
- Qwen-VL を llama.cpp のサーバーで動かすときは、起動の引数に `--image-min-tokens 1024` を付けてください。画像のトークンが少ないと、小さい画像で位置が大きくずれます。

## 何を送るか(OpenAI)

OpenAI の画像の API には四角を受ける項目がないため、「画像と文」で伝えます。

1. 1枚目の入力に、番号と色の付いた四角だけを重ねた画像を、サーバーが作ります(種類 `regions` の画像)。「動かす」は元の位置を点線、移す先を実線で描き、矢印でつなぎます。
2. この画像を、入力の後ろに足します。参照画像のうち入力に無いものは、その後ろに番号の順で足します。
3. プロンプトの後ろに、四角ごとの文を足します。画面の言語に合わせます。前置きで、プロンプトの中の「四角 1」のような番号や名前が、どの四角の場所を指すかを伝えます。
   - 指示のある四角: 「四角 2(青、帽子): 四角の中(横 50〜90%、縦 50〜90% の範囲)を変える。 指示: 赤くする」
   - 目印(指示の無い「変える」「足す」): 「四角 1(赤、右手の白いカフス): 横 10〜30%、縦 20〜40% の範囲。」
   - 名前が無ければ「四角 1(赤): …」です。

四角を描いた画像には番号だけを描き、名前は描きません(名前は文で番号と並べて伝えます)。

- 足す画像も、入力画像の枚数の上限(16 枚)に数えます。超えるときは送信できず、理由が出ます。
- 何を送ったかは Run に残ります。Run の詳細では、プロンプトに自分で書いた文を出し、その下の「足した文(領域の指示)」を開くと足した文が見られます。「領域の指示」には、送った四角の画像と、四角の一覧(名前・種類・指示)が出ます。入力にも四角を描いた画像が「領域」の印付きで出ます。履歴のカードには「領域 3」のように送った四角の数が出ます。
- 「同じ設定で新規作成」では、四角(名前も)を戻し、足した画像と文を除いて、自分で書いたプロンプトと入力に戻します。パラメーターセットには四角を入れません(四角は画像ごとのもの)。
- 四角を描いた画像は、既定ではストックに出しません(表示の設定の「スケッチ・マスク・配置・領域をストックに出す」で出せます)。系列グラフと Run の詳細からは開けます。

### 入力画像の無い生成(OpenAI)

OpenAI の生成の API は画像を受けないため、入力画像の無い Run の四角は、配置図にして Edit で送ります。

- 白紙の大きさは出力サイズの設定の幅×高さです(`auto` のときは 1024×1024)。四角の座標は出力の大きさに対する割合です。
- サーバーが、その大きさの白紙に四角と番号だけを描いた配置図(種類 `regions` の画像)を作り、唯一の入力(1枚目)にします。参照画像は、その後ろに番号の順で足します。
- 足す文は入力画像のある Run と分けます。前置きで「1枚目は白紙に四角を描いた配置図で、そのとおりに物を置いて新しい画像を描く」と伝え、結びで「白地・四角・番号は描かず、画面全体を絵で埋める」と伝えます。「変える」の四角は「四角の中に描く」という文になります。
- 選べる種類は「変える」「足す」だけです(白紙には残す物・消す物・動かす物がありません)。
- Run は Edit(`operation = edit`)として記録します。パラメーターは生成のフォームの値をそのまま送ります。表現の制限(`moderation`)は生成だけの項目なので送りません。そのため管理者設定の値は効かず、OpenAI の既定の判定になります(普通の生成より断られやすいことがあります)。
- 「同じ設定で新規作成」では、配置図と参照画像を入力に戻さず、入力画像の無いフォームに四角とプロンプト(足した文を除く)を戻します。

### 入力画像があって白紙の土台(OpenAI)

[土台を選ぶ](#土台を選ぶ)で白紙を選んだときです。

- 配置図の大きさと描き方は入力画像の無い生成と同じです(出力サイズの幅×高さ、`auto` のときは 1024×1024)。
- 配置図は、利用者の入力の後ろ、参照画像の前に足します。主たる入力(1枚目)は利用者の1枚目のままです。配置図も入力の枚数の上限に数えます。
- 足す文は白紙用で、「N枚目の画像は配置図。配置図のとおりに物を置いて新しい画像を描く。ほかの画像は参考に使う」と伝えます。四角の参照画像に入力の画像を選べば、その画像の番号で指します。
- 「同じ設定で新規作成」では、配置図と足した参照画像を外し、利用者の入力は残して、白紙の土台に四角を戻します。

## うまく伝えるには

- OpenAI の画像のモデルは四角を学んだモデルではないので、指示どおりにならないことがあります。効かないときは、全体のプロンプトにも同じことを書くと伝わりやすくなります。
- 四角は少なめにします。数が多いと、取り違えや無視が増えます。
- 四角は目安です。物より少し大きめに囲んで構いません。
- 動かす・足すでは、移す先・足す先の大きさを、出したい大きさに合わせます。

## ComfyUI

ComfyUI 本体の Create Bounding Boxes(`CreateBoundingBoxes`)を含むワークフローでは、四角をそのノードに差し込みます(ADR-0053 6章)。四角の形をモデルごとの形(FLUX.3 Layout Prompt、MOSS-Image Layout Prompt など)に直すのは、ワークフローの中の変換ノードに任せます。

### 差し込み先

- ワークフローの登録・編集画面の差し込み先に「四角(領域)」があります。出力につながる Create Bounding Boxes が1つなら、読み取りで自動で選ばれます。複数あれば、どれに差し込むかを問います。テンプレートに Create Bounding Boxes が無ければ、この行は出ません。
- 差し込むのはそのノードの `bboxes` 入力です。`bboxes` に別のノードが配線されていても、実行のときに差し込んだ値で上書きします。
- アシスタントの提案(ADR-0052)はこの項目を扱いません(読み取りの規則で見つけます)。
- 差し込み先を選んだワークフローだけ、生成のフォームに「領域」が出ます。

### 選べる種類

- 種類は「変える」と「足す」だけです。「そのまま残す」「消す」はノードの形で表せず(送ると物を足す指示になる)、「動かす」は元の位置を持てません。
- 四角ごとの参照画像は使えません(ノードに入口がありません)。札に参照画像の欄は出ません。
- 種類はノードに送りません。「変える」「足す」は、ノードから見ると同じ四角です。
- 選べない種類や参照画像の付いた四角があるまま ComfyUI のワークフローに切り替えると、四角は外れます(そのことが出ます)。

### 白紙のキャンバス

- 入力画像の無い生成では、出力の幅×高さの縦横比の白紙の上に描きます。幅・高さは、ワークフローの幅・高さの差し込み先の値(未指定ならワークフローの既定値)です。差し込み先が無いときは、四角のノードの `width` / `height` が定数か、整数の Primitive か、ComfyUI 本体の Resolution Selector への配線なら、そこから求めます。Resolution Selector の `aspect_ratio` などを公開パラメーターにしていれば、フォームで選んだ値で白紙の大きさも変わります(2026-10-22)。決められないときは、出力サイズの設定の大きさです。
- 四角は大きさに対する割合で持つので、後から幅・高さを変えても、四角は一緒に伸び縮みします。
- 白紙では検出は使えません(画像がありません)。
- 白紙に描いた四角は、入力画像を足しても白紙のままです。編集のワークフロー(入力画像のある Run)では、既定では1枚目の入力画像の上に描き、[土台を選ぶ](#土台を選ぶ)で白紙を選ぶと、出力の大きさに対する割合として差し込みます。

### 値の形

`bboxes` には、ノードが受ける「要素」の一覧を JSON の文字列にして入れます。番号の順に並べます(ノードは背景を先、前景を後に置く想定なので、番号もその順に付けると扱いやすくなります)。

```json
[
  {"type": "obj", "bbox": [150, 100, 700, 450], "desc": "眠る猫"},
  {"type": "text", "bbox": [200, 550, 500, 900], "text": "OPEN", "desc": "看板"}
]
```

- `bbox` は `[上, 左, 下, 右]`(`[ymin, xmin, ymax, xmax]`)で、0〜1000 の整数です。GAKEI の四角(左上を原点にした `[x0, y0, x1, y1]` の割合)を 1000 倍して四捨五入し、0〜1000 に収めます。ピクセルへは、ノードが自分の `width` / `height` で直します。ノードの `width` / `height` は、出力の大きさと同じ縦横比にしておいてください。変換ノード(MOSS-Image Layout Prompt など)の `width` / `height` も同じです。幅・高さの差し込み先が latent のノードだけを指しているワークフローで出力の大きさを変えると、四角のノードと変換ノードは元の大きさのままになります。幅・高さを Primitive にして、latent・四角のノード・変換ノードの3つに配線しておくと、そろったまま変えられます。
- `desc` は札の指示です。指示が無ければ名前、どちらも無ければ空です。
- 描く文字のある四角は `type` を `text` にし、`text` に描く文字を入れます。無ければ `obj` です。
- ノードの `width` / `height` が決まるときは、四角をキャンバスの値(`editor_state`)にピクセルで書き、`bboxes` と `last_incoming` は消します。実行の結果は `bboxes` に入れたときと同じで、送ったグラフがテンプレートと同じ形になります。`width` / `height` は、公開パラメーターを差し込んだ後の値で、定数、整数の Primitive(`PrimitiveInt` など)への配線、Resolution Selector の出力への配線から求めます(2026-10-22)。
- 決められないときは、要素を `bboxes` に入れ、同じノードの `last_incoming` を空(`{"__value__": []}`。API 形式では配列を `__value__` で包みます)にします。ノードは、前に受けた値と同じ値が来るとキャンバスの値を使うためです。キャンバスの値は古い四角を残さないよう空にします。
- 出力 PNG を ComfyUI に読み込んでも、キャンバスに四角は戻りません。ComfyUI は実行時(`execution.py` の `validate_inputs`)に `__value__` の包みを外した値をグラフに書き戻し、PNG の `prompt` にはその書き換え後のグラフが入ります。ComfyUI の画面は API 形式の読み込みで配列の値を配線とみなすので、包みの無い `editor_state` は捨てられます(ComfyUI に報告済み: https://github.com/Comfy-Org/ComfyUI/issues/17294)。四角を戻したいときは、Run の詳細の「ComfyUI に送ったグラフ(JSON)」の「JSON をダウンロード」で送ったグラフ(包みが残っています)を保存し、ComfyUI に読み込んでください(2026-10-22)。
- 四角が1つも無い Run では差し込みません。テンプレートのキャンバスの値がそのまま使われます。
- 差し込んだ値は、Run の詳細の「ComfyUI に送ったグラフ」(`run.params`)で確かめられます。プロンプトに文は足さず、重ねた画像も作りません。Run の詳細の「領域の指示」には、四角の一覧だけが出ます。

### 形が変わったら止まる

Create Bounding Boxes は本体に入って日が浅く、値の形が変わることがあります。四角を差し込む Run では、実行の前に ComfyUI の `/object_info/CreateBoundingBoxes` を見て、次を確かめます。

- `CreateBoundingBoxes` のノードがあること。
- `bboxes` 入力が文字列(`STRING`)を受けること。

どちらかが違えば、ComfyUI に送らずに Run を失敗にし、理由を出します(黙って違う形で送りません)。ComfyUI に届かないときは、ほかの通信の失敗と同じく Run が失敗します。

## 制限

- 1枚目の入力(無ければ白紙。入力画像があっても白紙を選べます)に付けます。1枚目の上の四角は、1枚目を入れ替える・外す・配置で作り直すと、位置を割合のまま新しい1枚目(または白紙)に移ります。白紙の四角は白紙のままです。選べない種類があるときだけ外れます(そのことが出ます)。
- 四角を受けないモデルに切り替えると、四角は外れます。
- 四角以外の形(多角形、自由な線、楕円)と回転はありません。
- MCP のツールは後の段です。
