# 領域の指示

入力画像の1枚目(主たる入力)の上に四角を描き、四角ごとに名前や「何をするか」を付けて Edit に渡します(ADR-0053)。「この四角の中を赤い帽子にする」「ここに看板を足して OPEN と描く」「この皿を右下へ動かす」のように、場所ごとに別々の指示を付けられます。

四角は場所と大きさの目安です。マスクのような厳密な範囲ではありません。形を細かく決めたいときは、マスクやスケッチを使います。

## 開く

生成のフォームで入力画像を1枚以上入れると、1枚目のチップ(サイドバーの配置ではタイル)に「領域」のボタンが出ます。押すと編集画面が開きます。

- 四角を受けるモデルでだけ出ます。今は OpenAI の Edit(と、確認用の `FAKE_PROVIDER=1`)です。ComfyUI と SD WebUI では出ません。
- 四角を付けると、1枚目に「領域 3」のように数が出ます。押すと続きを編集でき、横の「×」で外せます。

## プロンプトを書きながら見る

1枚目に四角か検出の候補があると、プロンプトの欄のすぐ上に「領域と検出の候補」が出ます。1枚目の画像に、四角(番号と色)と検出の候補(点線と名前)を重ねた小さなプレビューと、名前のチップを並べます。

- チップを押すと、その文字をプロンプトのカーソル位置に入れます(直前が空白でなければ、半角の空白を挟みます)。カーソルの位置が分からなければ末尾に入れます。タグの入力のときは、末尾にタグとして足します。
- 「四角 1」などのチップは、四角の番号を書くときに使います。送る文でも同じ呼び方(「四角 1」)で四角を指します。名前のある四角は、「四角 1 左のカバン」のように名前も添えて出します。
- 検出の候補(点線)のチップは、枠が点線で、文字が淡く出ます。**点線の候補は送られません。** 候補のチップを押すと、名前をプロンプトに入れるのと一緒に、その候補を名前の付いた四角(種類は「変える」、指示なし)にします。押した後は「四角 n 名前」のチップに変わり、押し直しても四角は増えません。チップを押すか、「領域」の画面で四角にしたものだけが、四角を描いた画像と文として送られます。
- チップにマウスを重ねる(スマートフォンでは触れる)と、対応する四角や候補を強調します。
- プレビューを押すと大きく見られます。
- 見出しを押すと畳めます。1枚目のチップ・タイルの目のボタンでも出し入れできます。開いているかはブラウザごとに覚えます。
- 出す検出は、「領域」の画面で選んだ検出です(選んでいなければ、いちばん新しい検出)。

## 四角を描く

| 操作 | やり方 |
|---|---|
| 描く | 画像の上の何も無い所をドラッグ(選んでいない四角の内側でも描ける) |
| 選ぶ | 四角の枠か番号を押す。下(広い画面では右)の札からも選べる |
| 動かす | 選んだ四角の内側をドラッグ。矢印キーでも少しずつ動かせる(Shift で大きく) |
| 大きさを変える | 選んだ四角の角と辺のハンドルをドラッグ |
| 外す | 札のごみ箱、ツールバーのごみ箱、または Delete キー |
| 番号を入れ替える | 札の上下の矢印 |
| 元に戻す・やり直す | ボタン、または Ctrl+Z / Shift+Ctrl+Z(Mac は Cmd) |
| 拡大 | ツールバーの拡大・縮小・全体を表示。拡大したときは「画面を動かす」に切り替えるとドラッグで表示を動かせる |

四角は最大 16 個です。四角は画像に対する割合で持つので、拡大しても位置はずれません。タッチの画面でも、指で描いて動かせます。

四角には番号と色が付きます。色は番号の順に赤・青・緑・黄・マゼンタ・水色・オレンジ・紫で、9 個目からは繰り返します。送る画像に描く色と同じです。

## 札

四角ごとに札が出ます。

- **名前(任意):** その四角が何か(「右手の白いカフス」など)。検出の候補から作った四角には、候補の名前が入ります(直せます)。画像の上の四角の横にも出ます。
- **種類:** 変える(既定)/足す/そのまま残す/消す/動かす。
- **指示(任意):** その四角で何をするか。
- **描く文字:** 看板などに描かせる文字。指示とは分けて、そのまま渡します。
- **参照画像:** その四角に使う画像。入力の画像かストックから選びます。入力に無い画像を選ぶと、送るときに入力の後ろに足します。

四角の定義(位置と名前)と指示は分けて扱います。指示は無くても保存して送れます。

- 指示・描く文字・参照画像のどれも無い「変える」「足す」の四角は、**目印**になります。送る文では、場所と名前だけを示します(「四角 1(赤、右手の白いカフス): 横 10〜30%、縦 20〜40% の範囲。」)。全体のプロンプトから「四角 1 のカフスを金色にする」「白いカフスを外す」のように、番号か名前で指して使います。
- 「そのまま残す」「消す」「動かす」は、指示が無くても種類のとおりに伝えます。
- 保存できないのは、四角の位置が正しくないとき、「動かす」の元の位置が無いとき、文字数の上限(名前 100 文字、指示 2000 文字、描く文字 200 文字)を超えたときだけです。

指示の欄の下には、出している検出の名前のチップが並びます。押すと、指示の欄のカーソル位置に入れます。

画像の上の名前は、近い四角どうしで重なるときは上下にずらして出します。

### 動かす

種類を「動かす」にすると、今の四角が元の位置(点線)になり、横に移す先の四角(実線)ができます。矢印が元の位置から移す先を指します。どちらの四角も動かしたり大きさを変えたりできます。

## 検出

管理者が「領域の検出」を有効にしていると、編集画面に「検出」が出ます。VLM が画像の中の物を探し、四角の候補を点線で出します。候補を押すと四角になり、札ができます(名前には候補の名前が入ります。指示は空のままでも送れます)。

- 「探す物」に言葉を入れると、それに当てはまる物を探します(「カップ」「左の人の服」など)。空なら主な物を一通り(20 個まで)挙げます。
- 1 回に 10 秒以上かかることがあります。待っている間は「取り消す」で止められます。
- 検出の結果は画像ごとに履歴として残ります。編集画面を開くと、いちばん新しい検出の候補が出ます。「検出の履歴」で前の検出に切り替えたり、履歴から消したりできます(消せるのは検出した人と管理者)。「候補を隠す」を選ぶと候補を出しません。検出が無効になっても、履歴は見られます。
- 縦に長い物(鉢植え、風船の紐など)は、下の端が短く出ることがあります。四角を直してから使ってください。
- 物の多い絵では、細かすぎる候補も混じります。使う物だけを選んでください。

検出しなくても、四角は手で描けます。

### 管理者の設定

管理者設定の「領域の検出」で設定します。

- **有効にする:** 既定は無効です。
- **接続先とモデル名:** 「LLM の接続先」から、画像を読めて、構造化出力(JSON のスキーマ)に対応する接続先を選びます。既定は OpenAI の `gpt-5.6-luna` です。手元の VLM のサーバーは後の段で対応します。
- **1 時間の上限:** 利用者ごとに、直近 1 時間に検出できる数です。

検出では、画像(長辺を縮めたもの)と指示を接続先へ送り、そのたびに費用がかかります。送る前に Mod の `ai.before_send`(用途 `region_detection`)を呼びます([docs/mods.md](mods.md))。

## 何を送るか(OpenAI)

OpenAI の画像の API には四角を受ける項目がないため、「画像と文」で伝えます。

1. 1枚目の入力に、番号と色の付いた四角だけを重ねた画像を、サーバーが作ります(種類 `regions` の画像)。「動かす」は元の位置を点線、移す先を実線で描き、矢印でつなぎます。
2. この画像を、入力の後ろに足します。参照画像のうち入力に無いものは、その後ろに番号の順で足します。
3. プロンプトの後ろに、四角ごとの文を足します。画面の言語に合わせます。前置きで、プロンプトの中の「四角 1」のような番号や名前が、どの四角の場所を指すかを伝えます。
   - 指示のある四角: 「四角 2(青、帽子): 四角の中(横 50〜90%、縦 50〜90% の範囲)を変える。 指示: 赤くする」
   - 目印(指示の無い「変える」「足す」): 「四角 1(赤、右手の白いカフス): 横 10〜30%、縦 20〜40% の範囲。」
   - 名前が無ければ「四角 1(赤): …」です。

四角を描いた画像には番号だけを描き、名前は描きません(名前は文で番号と並べて伝えます)。

- 足す画像も、入力画像の枚数の上限(16 枚)に数えます。超えるときは送信できず、理由が出ます。
- 何を送ったかは Run に残ります。Run の詳細では、プロンプトに自分で書いた文を出し、その下の「足した文(領域の指示)」を開くと足した文が見られます。「領域の指示」には、送った四角の画像と、四角の一覧(名前・種類・指示)が出ます。入力にも四角を描いた画像が「領域」の印付きで出ます。履歴のカードには「領域 3」のように送った四角の数が出ます。
- 「同じ設定で新規作成」では、四角(名前も)を戻し、足した画像と文を除いて、自分で書いたプロンプトと入力に戻します。パラメーターセットには四角を入れません(四角は画像ごとのもの)。
- 四角を描いた画像は、既定ではストックに出しません(表示の設定の「スケッチ・マスク・配置・領域をストックに出す」で出せます)。系列グラフと Run の詳細からは開けます。

## うまく伝えるには

- OpenAI の画像のモデルは四角を学んだモデルではないので、指示どおりにならないことがあります。効かないときは、全体のプロンプトにも同じことを書くと伝わりやすくなります。
- 四角は少なめにします。数が多いと、取り違えや無視が増えます。
- 四角は目安です。物より少し大きめに囲んで構いません。
- 動かす・足すでは、移す先・足す先の大きさを、出したい大きさに合わせます。

## 制限

- 1枚目の入力だけに付けられます。1枚目を入れ替える・外すと、四角は外れます(そのことが出ます)。
- 四角を受けないモデルに切り替えると、四角は外れます。
- 四角以外の形(多角形、自由な線、楕円)と回転はありません。
- ComfyUI への差し込み、手元の VLM での検出、MCP のツールは後の段です。
