# ADR-0039: プロンプトをタグで編集する(画像のタグのコピーと、タグ編集モード)

**Status:** Proposed
**Date:** 2026-10-10

## Context

SD WebUI(ADR-0038)のプロンプトは、`1girl, smile, cherry blossoms` のような Danbooru 系のタグをカンマで並べて書くことが多い。GAKEI は WD Tagger(ADR-0024 3章)で画像に同じ語彙のタグを付けられるので、既存の画像のタグを、そのまま次の生成のプロンプトに使える。

タグで書くか文章で書くかは、プロバイダーではなく、その先のモデルの学習のしかたで決まる。Danbooru 系のタグで学習したチェックポイント(SDXL のアニメ系など)はタグが向き、Flux や Qwen-Image、OpenAI の画像モデルは文章が向く。同じ ComfyUI でも、ワークフローのモデル次第でどちらにもなる。モデルの名前やファイルからこれを確実に判定する方法は無い。

一方、スマートフォンでカンマ区切りの長い文字列を編集するのは難しい。タグを1つ消すにも、カーソルを合わせて文字を消す必要がある。

使える材料:

- `asset_tag`(ADR-0024)。WD Tagger のタグは英語で、`_` を空白に置き換えてある。`score` を持つ。ただし訳したタグも `score` を引き継ぐので、`score` だけでは WD Tagger のタグと区別できない。
- WD Tagger の語彙 `selected_tags.csv`(約 1 万 1 千行、約 300KB。`name`、`category`、`count`)。WD Tagger を有効にした環境では `DATA_DIR/models/wd/` に既にある。括弧を含むタグが約 1600 ある(例: `xxx (cosplay)`)。SD のプロンプトでは括弧が強調の記法なので、`\(` と書く必要がある。

## Decision

### 1. 画像のタグをプロンプトにする

- 画像(ビューアと Asset の詳細)に「タグをプロンプトに使う」を置く。どのプロバイダーの画像でも、アップロード画像でもよい。
  - **コピー:** カンマ区切りの文字列をクリップボードに入れる。
  - **フォームに送る:** 生成のフォームのプロンプトにタグを入れる(今の入力を置き換えるか、後ろに足すかを選ぶ)。プロバイダーとモデルは今の選択のまま変えない。
- 入れるタグ: 人が消したもの(`removed`)を除き、**WD Tagger の語彙にあるもの**(訳や VLM の日本語のタグは入らない)を、`score` の高い順に、続けて人が付けた語彙にあるタグを並べる。語彙が無い環境(WD Tagger を使っていない)では、英数字だけのタグを入れる。
- 括弧は `\(`、`\)` にエスケープする(SD WebUI と ComfyUI では括弧が強調の記法のため)。フォームに送るときは、OpenAI のフォームではエスケープしない。

### 2. タグ編集モード(すべてのプロバイダー。モデルごとに覚える)

- プロンプト欄(とネガティブプロンプト欄があればそれも)に「テキスト / タグ」の切り替えを置く。プロバイダーでは限らない。
- **モードはモデルごとに覚える。** ブラウザに `(プロバイダー, モデル)` ごとのモードを保存し、そのモデルを選ぶとそのモードで開く。初めてのモデルはテキストモード。GAKEI はモデルの種類を判定しない(Context)。管理者がモデルごとの既定を決める設定も、今は作らない(使ってみて要るなら足す)。
- **タグモード:** プロンプトをトップレベルのカンマで区切り、1つずつチップで出す。
  - チップの × で、ワンタップで消す。
  - 入力欄に文字を打つと候補を出し、タップで足す。候補は WD Tagger の語彙(`count` の多い順)と、GAKEI のタグのうち英数字のもの。足すときに括弧をエスケープし、`_` は空白にする。
  - 括弧・角括弧・波括弧の中のカンマでは区切らない。`(tag:1.2)`、`<lora:…>`、`{a|b}`(Dynamic Prompts)、`BREAK` は、それぞれ1つのチップとして、中身を変えずに扱う(重みの調整や並べ替えは、タグモードでは作らない。テキストモードで直す)。
  - 2つのモードは同じ文字列を編集する。タグモードで編集しても、区切りを `, ` に揃える以外は文字列を書き換えない。
- 候補の API は `GET /api/tags/suggestions?q=`(プロバイダーに依らない)(前方一致を優先し、最大 20 件)。語彙はサーバーが起動後に一度だけ読み込む。語彙のファイルが無ければ GAKEI のタグだけを使う。候補のためだけに WD Tagger のモデルをダウンロードすることはしない。
- 狭い幅(768px 未満)で使いやすいことを優先する。チップは指で押せる大きさにし、候補は入力欄のすぐ下に出す(ADR-0009)。

### 作らないもの

- タグの重みのスライダー、ドラッグでの並べ替え
- モデルがタグ向きか文章向きかの自動判定、管理者によるモデルごとの既定
- 語彙の翻訳(日本語で打って英語のタグを出す)。2026-10-10 に ADR-0041(タグ辞書)で対象にした
- WD Tagger 以外の語彙(e621 など)の取り込み。2026-10-10 に ADR-0041 で、利用者が登録する辞書として対象にした

## Consequences

- ADR-0024 のタグが、検索だけでなく次の生成の材料にもなる。
- 来歴は変わらない。送ったプロンプトは、これまでどおり Run に記録される(ADR-0003)。
