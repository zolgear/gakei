# ADR-0029: ログイン不要の共有リンク(画像1枚、または系列)

**Status:** Proposed
**Date:** 2026-09-30

2026-09-30 にユーザーが次のように決めた。

- 共有の相手は、ログイン不要のリンクを知っている人(URL を知っていれば誰でも見られる)。同じ GAKEI の利用者どうしで見せ合う機能は作らない。
- 共有の単位は、画像1枚か、その画像の系列。系列の範囲は、共有するときに「この1枚」「祖先まで」「祖先と子孫」から選ぶ。範囲は共有した時点で固定する。
- 見せるのは、画像と、それを作ったときのプロンプト・パラメーター。
- 有効期限は設けない。取り消すまで有効。
- 機能そのものは、管理者設定で有効にしたときだけ使える(既定は無効)。
- 原本(4K)を見られるか・ダウンロードできるかは、共有するときに選ぶ(既定は許す)。

同日、この ADR の内容がユーザーに承認された。タグを公開に含めるかはユーザーが迷ったうえで、今回は含めないことにした(3章)。

Issue [#36](https://github.com/zolgear/gakei/issues/36)。

## Context

ADR-0001 は「共有リンク」と「外部公開」を非ゴールにし、ADR-0025 は認証モードで本人のものだけを見せると決めて、共有機能を将来の課題にした。今は、生成した画像を人に見せるには、ダウンロードして別の手段で渡すしかない。そうすると、プロンプトやパラメーター、どの画像から Edit したかという GAKEI の記録(ADR-0003)が伝わらない。

ADR-0025 は、可視性の判定を1か所(`domain/visibility.py`)に集め、共有を足すときに広げられるようにしてある。

## Decision

### 1. 共有リンク

- 共有は、画像(Asset)1つを起点に作る。作れるのは、その Asset を見られる人(ADR-0025)だけ。
- リンクは `{PUBLIC_BASE_URL}/s/{トークン}` の形にする。トークンは推測できない乱数(`secrets.token_urlsafe(32)`)。`PUBLIC_BASE_URL` が無ければ、リクエストの URL から組み立てる(MCP の `resolve_public_base` と同じ)。
- トークンは DB にそのまま保存する。共有した人が、あとからリンクをもう一度コピーできるようにするため。ダウンロード用の1回限りの URL(ADR-0023 8章)のようにハッシュだけを持つ方式は採らない。DB を読める人は、共有に関係なくすべての画像を読めるので、平文で持っても守る範囲は変わらない。
- 有効期限は無い。取り消すまで有効。
- 取り消しは、共有した人がいつでもできる。取り消したリンクは 404 になり、元に戻せない(もう一度共有すると、新しいトークンになる)。
- 1つの Asset に、範囲や設定の違う共有を複数作れる。

### 2. 範囲(共有した時点で固定)

共有するときに、次の3つから選ぶ。

| 範囲 | 含まれる画像 |
|---|---|
| この1枚 | 起点の Asset だけ |
| 祖先まで | 起点と、その祖先(系列のグラフ(ADR-0003)を親の方向にたどって現れる Asset) |
| 祖先と子孫 | 上に加えて、子孫(子の方向にたどって現れる Asset) |

- 系列のグラフは、共有した人から見えるもの(ADR-0025)だけで作る。系列の自称の参照(ADR-0014)が指す、表示できない Asset や別のインスタンスの Asset は含めない。
- 含まれる Asset の一覧を、共有を作った時点で保存する。そのあと作った子孫は、自動では載らない(意図せず公開しないため)。載せたければ、新しく共有を作る。
- 共有を作る画面では、含まれる画像の枚数とサムネイルを見せてから作る。何が外に出るかを、作る前に確かめられるようにするため。
- 含まれる Asset を、あとで論理削除した場合は、共有のページからも消える。起点の Asset を削除した場合は、共有そのものが 404 になる。

### 3. 見せるもの・見せないもの

見せるもの:
- 画像(サムネイル、プレビュー。原本は4章)。
- 画像のタイトル(ADR-0024)。
- その画像を作った Run のプロンプトとパラメーター(モデル、サイズ、品質など、Run の詳細画面に出しているもの)と、作成日時。
- ComfyUI の Run では、最終プロンプト(PE の出力など。ADR-0030)。プロンプトの下に出す(2026-09-30 追記)。
- 範囲が「祖先まで」「祖先と子孫」のときは、含まれる画像どうしの系列のグラフ。Run のノードは、プロンプトとパラメーターの表示に使う。
- Run の詳細(2026-09-30 追記)。GAKEI の系列のグラフ(画像と Run のノード)ごと見せるのが共有の主な価値なので、グラフの Run のノードを選ぶと、その Run の詳細を共有のページの中に出す(その Run が作った画像に移るだけにはしない)。項目は通常の画面の Run の詳細にそろえ、見せないもの(下)は出さない。
  - プロンプト、最終プロンプト(ADR-0030)、操作(生成/編集)、モデル、パラメーター、作成日時。
  - 入力と出力は、共有に含まれる画像だけを出す。入力は、主たる親(`position = 0` の `image`)と参照(マスク、スケッチなど)を分けて出す。範囲外の入力・出力は、枚数も出さない。
  - Edit の Run で、主たる親と出力の両方が共有に含まれるときは、「編集前と比較する」を出す。比較に使う画像は共有のページの配信から取り、原本の可否(4章)に従う(許さない共有ではプレビューまで)。
  - Run を直接開ける URL `/s/{トークン}/runs/{run_id}` を持つ。共有に含まれる画像を作った Run でなければ、ほかと同じく 404 にする。
  - グラフの見た目は通常の画面の系列のグラフにそろえる(主たる親は実線、参照は破線、ノードの種類の表示)。
  - 同じ Run のほかの出力(兄弟)は、範囲の決め方(2章)を変えずに扱う。兄弟も見せたいときは、親を起点に「祖先と子孫」で共有する。
- 系列グラフを広げる(2026-10-01 追記)。系列の長さと枝分かれは GAKEI の共有でしか見せられないものなので、小さなグラフのままにしない。
  - 共有のページの系列グラフに「広げる」を置き、グラフだけを全画面で表示する。URL は `/s/{トークン}/lineage` で、直リンクで開ける。系列を含まない「この1枚」の共有や無効なトークンでは、ほかと同じく扱う(「この1枚」ではグラフを出さないので「広げる」も出さない)。
  - 開いたときは系列全体が収まる倍率にする。全画面ではノードのサムネイルを通常のグラフより大きくし、レイアウトの間隔もそれに合わせる。開いている画像(または Run)のノードは、通常のグラフと同じく強調する。
  - 画像のノードを押すと全画面を閉じてビューアでその画像を開き、Generated のノードを押すと全画面を閉じてその Run の詳細を開く。「ビューアに戻る」で全画面を閉じる。
  - 見せる範囲は変えない(見せ方だけ)。共有を開いたときの最初の表示は、これまでどおりビューアで起点の画像。
  - 狭い幅(768px 未満)でも全画面で操作できる(ADR-0009)。

見せないもの:
- 実行者やアップロードした人の名前、メールアドレス、アバター。
- 料金と usage、採用/不採用の印、グループ。
- タグ(ADR-0024)。含めるかを検討したうえで、今回は見送った。自動で付いたタグには、利用者が意図しない語が入りうるため。必要になったら、共有するときに選べる形で足す。
- 共有に含まれない Asset(グラフの中でも、表示できないノードとしても出さない)。
- 画像に埋め込まれた他のツールの生成メタ情報(ADR-0018)。プロンプトは GAKEI の Run の記録から見せる。
- 失敗した Run、取り消した Run。グラフにも Run の詳細にも出さない(2026-09-30 に再確認。拒否されたプロンプトを外に出さないため)。

### 4. 原本

- 共有するときに「原本の表示とダウンロードを許す」を選ぶ(既定は許す)。
- 許す場合は、ビューアで原本まで拡大でき、ダウンロードもできる。ダウンロードする PNG に系列情報を埋め込む処理(ADR-0014)は行わない(インスタンスの中の id を外に出さないため)。
- 許さない場合は、プレビュー(長辺 2048px)までにする。原本の配信は 404 にする。

### 5. 有効にする設定

- 管理者設定に「共有リンク」の有効・無効を置く。既定は無効。MCP(ADR-0023)と同じく、外に出す機能なので、管理者が明示して有効にしたときだけ使えるようにする。
- 無効のときは、共有を作る操作を画面に出さず、既存の共有リンクもすべて 404 にする(共有の記録は消さない。有効に戻せば、取り消していないリンクはまた使える)。ユーザー設定の共有の一覧も出さず、機能の存在ごと隠す(有効に戻せば、一覧と取り消しができる。無効のあいだは、リンクはどれも開けないので、取り消せなくても困らない)。
- 個人モード(`AUTH_MODE=none`)でも使える。ただし、個人モードは認証が無いので、サーバーをそのまま外に出すと、共有していない画像も含めて全部が見える。外に出すのは共有のページに要るパスだけにする(6章)。この注意は `docs/` にだけ書き、管理者設定の画面には書かない(逆プロキシの構成は画面で変えられない運用上の情報なので、画面に置いても操作につながらない)。

### 6. 公開する URL を分ける

- 共有のページとその API は、ほかのパスと分ける。逆プロキシで、これらのパスだけを外に出せるようにするため。
  - 画面: `/s/{トークン}`(SPA の画面。ログインを求めない)
  - API: `/api/public/shares/{トークン}` と、その下の画像の配信 `/api/public/shares/{トークン}/assets/{asset_id}/content?variant=`
  - 画面に要る静的ファイル: `/static/`、favicon など
- `/api/public/` の下のルートには `require_user` を掛けない。かわりに、トークンが有効で、機能が有効で、指定された Asset が共有の範囲に含まれることを、1つの関数で確かめる。どれかが違えば、理由を区別せず 404 を返す。
- 共有の API は、共有の範囲の外の Asset や Run、ほかの利用者の情報を返さない。可視性の判定(ADR-0025)とは別に、共有の範囲だけを見る関数を置き、テストで REST の全ルートから公開のルートを洗い出して確かめる。
- 応答には `X-Robots-Tag: noindex`、`Referrer-Policy: no-referrer` を付ける。画像の `Cache-Control` は `private` にし、`immutable` は付けない(取り消したあとも長くキャッシュに残らないように、`max-age` を短くする)。
- `docs/` に、逆プロキシで公開のパスだけを外に出す設定例を書く。

### 7. 管理と記録

- 共有した人は、自分が作った共有の一覧(起点の画像、範囲、原本の可否、作成日時、最後に開かれた日時、開かれた回数)を見て、リンクのコピーと取り消しができる。
- 管理者も、他人の共有の一覧は見られない(ADR-0025 5章と同じ)。
- 共有の記録(`share`)は、作成者、作成日時、取り消した日時を持つ。取り消しは論理削除で、行は消さない。開かれた日時と回数は、証跡ではない情報として更新してよい。
- MCP(ADR-0023)には共有を作るツールを足さない。外に公開する操作なので、人が画面で行う。

### 8. ADR-0001 と ADR-0025 の改訂

- ADR-0001 の非ゴールから「共有リンク」を外し、「外部公開」を「外部公開(この ADR の共有リンクを除く)」に改める。
- ADR-0025 の「共有機能は作らない」に、この ADR で足したことを注記する。利用者どうしで見せ合う機能は、引き続き作らない。

## Options Considered

### 相手

| 案 | 評価 |
|---|---|
| A: ログイン不要のリンク(採用) | 組織の外の人にも見せられる。個人モードでも使える。リンクが漏れれば誰でも見られる |
| B: 同じ GAKEI の利用者だけ | 認証モードでしか意味がない。外の人には見せられない |

### 範囲の決め方

| 案 | 評価 |
|---|---|
| A: 共有した時点で固定(採用) | 何が公開されているかが、作った時点から変わらない |
| B: 開くたびに系列をたどる | あとで作った子孫も見えるが、意図せず公開するおそれがある |

### トークンの持ち方

| 案 | 評価 |
|---|---|
| A: 平文で保存(採用) | あとからリンクをコピーできる。DB を読める人はもともと全部の画像を読める |
| B: ハッシュだけ保存 | DB が漏れてもリンクは分からないが、リンクは作ったときに1回しか表示できない |

## Trade-off Analysis

ADR-0001 が共有リンクを非ゴールにしたのは、組織の中だけで使う前提だったからである。個人がセルフホストする使い方(ADR-0012)が増え、GAKEI の記録ごと人に見せたい場面が出てきた。外に出る範囲を小さく保つため、機能は既定で無効にし、範囲は共有した時点で固定し、見せる情報を画像とプロンプト・パラメーターに絞る。公開のパスを分けておけば、個人モードでも、逆プロキシで共有のページだけを外に出せる。

## Consequences

- 生成した画像を、プロンプトや系列ごと、ログインしていない人に見せられる。
- 認証なしで応答するルートが、`/api/auth/*` のほかに初めて増える。範囲の検査を1か所に集め、テストで確かめる。
- 新しいテーブル `share` と、共有に含まれる Asset の一覧のテーブルが加わる(マイグレーション)。
- 画面に、共有を作るダイアログ、共有の一覧、ログイン不要の共有のページが加わる。文言は日本語と英語(ADR-0015)。
