# 入力画像の配置

複数の画像を1枚のキャンバスに並べ、移動・拡大縮小・回転・四隅の変形・反転をして、1枚の入力画像にします(ADR-0050)。キャラクターの立ち絵や小物を、ただの参照画像として渡すのではなく、おおよその位置・大きさ・組み合わせを仮組みしてから、Edit で結合・仕上げをさせる使い方を想定しています。

配置の編集画面は WebGL2 で描きます。WebGL2 が使えないブラウザでは開けません(そのことを示します)。

## 開く

- **生成のフォームから:** 入力画像の並び(「追加」「スケッチ」の隣)の「配置」を押します。そのときの入力画像をすべて素材にし、重ならないようにキャンバスに収めて並べた状態から始まります。入力画像が無くても開け、「素材を追加」から選べます。
- **ストックから:** 「選択」で画像を選び、下の「配置で開く」を押します。
- **ビューアから:** 見出しの行の「配置で開く」を押します。

ストックとビューアから開いた場合は、保存すると生成の画面へ移り、配置の結果が入力に入ります。

## キャンバス

- **大きさ:** 既定は1枚目の画像の大きさ(入力画像が無ければ、生成のフォームで選んでいるサイズ、それも決まっていなければ 1024×1024)。フォームのサイズ、よく使う大きさ、カスタム(64〜3840 px)から選べます。大きさを変えると、素材は並びを保ったまま新しいキャンバスに収まります。
- **背景:** 白か透明。透明を選ぶと、素材の無い所は透明な PNG になります。
- キャンバスの外にはみ出した部分は暗く表示され、保存した画像には入りません。

## 素材の操作

| 操作 | やり方 |
|---|---|
| 選ぶ | 素材を押す。右の「素材」の一覧からも選べる |
| 移動 | ドラッグ。矢印キーで 1 px(Shift で 10 px)ずつ |
| 拡大縮小 | 四隅のハンドルをドラッグ(縦横比を保つ。中心は動かない) |
| 回転 | 上の丸をドラッグ。Shift を押すと 15° 刻み |
| 2本指 | 選んだ素材を、ピンチで拡大縮小しながら回転・移動 |
| 数値の入力 | 「選んだ素材」の中心 X・Y、倍率(元の大きさに対する %)、角度 |
| 反転 | 左右反転・上下反転 |
| 重ね順 | 前面へ・背面へ |
| 複製・外す | 複製、素材を外す(Delete キーでも外せる) |
| キャンバスに合わせる・中央に寄せる | 選んだ素材をキャンバスいっぱいに収める・中央に置く |
| 元に戻す・やり直す | ボタン、または Ctrl+Z / Shift+Ctrl+Z(Mac は Cmd) |

素材は最大 16 枚です。マスクは素材にできません。

### 変形(四隅)

ツールバーの「変形」に切り替えると、四隅のハンドルを1つずつ動かせます。画像を平らな面のまま、四隅を引っ張って台形や平行四辺形などに伸ばせます。奥行きは付きません(斜めから見た板のように、短い辺の側へ絵が詰まることはありません。どの辺の上でも絵の間隔は均等です)。凹んだ形やねじれた形にはならないよう、そうなる手前でハンドルが止まります。描画は四角形全体を1つの写像(双一次の写像)で描くので、変形した素材も継ぎ目なく描かれます。

以前の版で保存した配置(四隅の変形を射影変換で描いていたころのもの)も「配置を編集」で開けます。開くと今の描き方で描き直されます。

### 主たる素材

素材のうち1つが「主」になり、系列で配置の結果の主たる親として描かれます(ほかの素材は参照として描かれます)。既定は最初に追加した素材で、「主にする」で入れ替えられます。

## 保存と入力

保存すると、ブラウザで描いた PNG と配置の記録(レシピ)を保存し、配置の結果を入力の1枚目(主たる入力)に置きます。

- 素材にした元の画像は、既定では参照として入力に残ります。配置で縮めた画像だけでは細部が伝わらないためです(入力の枚数と費用は増えます)。
- 保存の欄の「元の画像を入力から外す」を選ぶと、素材にした画像を入力から外します。
- 入力画像を1枚しか取れないモデル(SD WebUI、ComfyUI など)では、配置の結果だけが入力になります。
- 入力の上限を超える分は入れず、そのことを示します。
- 1枚目が変わるので、マスクは外れます。必要なら描き直してください。

## 作り直す

入力にある配置の結果には「配置を編集」が出ます。押すと、保存したときの配置から続きを編集できます。

- 元の配置がまだどの実行の入力にもなっていなければ、新しい配置に置き換わります(系列のノードは増えません)。
- 既に実行に使っていれば、元の配置は証跡として残り、新しい配置が別に作られます。
- 削除された素材は読めないので、その素材を外して開き、そのことを示します。

## 系列

配置の結果は、素材の画像から配置の結果へ向かう辺で系列グラフに描かれます(実行は挟みません)。主たる素材は実線、ほかの素材は破線(参照)です。系列の ZIP、共有リンク、ダウンロードした PNG への埋め込みにも入ります。

## ストック

配置の結果は、スケッチ・マスクと同じく、既定ではストックに出ません。設定 → 表示の「スケッチ・マスク・配置をストックに出す」をオンにすると、ストックの種類に「配置」が出ます。

## できないこと

- **見る角度の変更(3D)はできません。** 回転は画面の中の回転と、四隅の変形までです。正面向きの絵を横向きにするといった変更は、置き方の仮組みを手がかりに、向きや角度を Edit のプロンプトで言葉で指示します。
- 素材の切り抜き、背景の除去、曲げる変形、透明度やフィルター、文字や図形はありません。描き足しは、配置の結果に「この画像の上に描く」(スケッチ)で行えます。
- 保存した PNG が正です。レシピは「何をどう置いたか」の記録で、レシピから同じ画素が作れることは保証しません。

## プロンプトの例

配置の結果を1枚目、元の画像を参照として残したまま Edit に送る場合の例です。

- 「1枚目の画像は構図の下書きです。人物と小物の位置・大きさ・重なりをこのとおりに保ち、2枚目以降の画像を見た目の参考にして、自然な1枚の絵に仕上げてください。継ぎ目や白い背景は残さないでください。」
- 「左の人物は、体を少し右へ向けた斜めの角度で描き直してください。位置と大きさは1枚目のとおりにし、顔と服のデザインは参照画像のとおりにしてください。」
- 「手前の箱は上の辺を短くした台形に置いています。床に置かれて奥へ続く箱として、遠近感を付けて描いてください。」
- 「背景は透明の部分を夕方の街並みにしてください。前景の配置は変えないでください。」
