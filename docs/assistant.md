# 生成のアシスタント

右端のアイコンの列の一番下にあるボタンか、Alt+A(Mac は Option+A)でアシスタントの窓を開き、チャットで頼みごとができます(ADR-0048)。窓はどの画面でも上に重ねて開き、動かしたり大きさを変えたりできます。もう一度押すと閉じます。

- プロンプトを作る・直す・訳す。作ったプロンプトはカードで示し、「フォームに入れる」「フォームを置き換える」「コピー」のボタンでフォームに入れます。
- プロンプトセットを読む・作る・編集する。
- 添付したストックの画像を見て、プロンプトを作る。
- 生成・Edit を実行し、結果を見て次を作る。たとえば「雰囲気の違う画像を3枚」や、「三面図を、正面から1枚ずつ」のような作業です。
- ストックの画像を探し、見つけた画像をカードで示す。
- 生成フォームの値(モデル、プロンプト、パラメーター、入力画像、グループ)を書き換える。
- スタジオの結果エリアに出ている生成結果を、画像とタグ・元のプロンプトから読み、直すための Edit のプロンプトを作る。
- ストックの画像にタグとタイトルを付け、グループに振り分ける。

既定では無効です。管理者設定の「アシスタント」(`/settings/assistant`)で有効にします。

## 設定

管理者設定の「アシスタント」で、次を決めます。変えた値は、ページ上部の「保存」を押すまで反映されません(ADR-0031)。

| 項目 | 内容 | 既定 |
|---|---|---|
| 有効 | パネルを出し、発言を受け付ける | 無効 |
| 接続先 | 「LLM の接続先」(`/settings/llm-connections`)で登録した接続先から選ぶ | OpenAI の設定 |
| モデル | 接続先のモデル名。道具の呼び出し(tool calling)に対応したモデルが要る。画像を添付するなら、画像入力にも対応したモデルにする | `gpt-5.6-luna` |
| LLM の 1 時間の上限 | 利用者ごとの、LLM へのリクエストの回数 | 200 |
| 1 回の発言の Run の上限 | 1 回の発言で作れる Run の数 | 20 |
| 1 時間の Run の上限 | 利用者ごとに、アシスタントが作れる Run の数。0 にすると生成を止める | 60 |

- 1 回の発言で、アシスタントが道具を呼べるのは 40 回までです。
- LLM の 1 時間の上限はプロセスの中で数えるので、再起動すると 0 に戻ります。Run の上限は、実行元がアシスタントの Run を DB で数えます。
- 上限に達すると、アシスタントは Run を作らずに、その旨を伝えます。

### 接続先の API 形式

接続先の API 形式(Responses / Chat Completions)は、「LLM の接続先」で選びます。

- **OpenAI 本体には Responses を使います。** OpenAI の推論モデル(gpt-5.6 や GPT-6 系など)は、Chat Completions では、推論を切ったとき(`reasoning_effort: "none"`)しか道具を使えません。Chat Completions を選んだ場合、GAKEI はこの断りを受けたときに推論を切って送り直します。その分、応答の質が下がることがあります。
- **ローカルの LLM(vLLM、llama.cpp、Ollama など)には Chat Completions を使います。** Qwen3 などの道具の呼び出しは、これらのサーバーの `/v1/chat/completions` で動きます。サーバー側で、道具の呼び出しを有効にしておきます(vLLM ではツール呼び出しのパーサーの指定、llama.cpp では `--jinja`)。

## 送るもの

**アシスタントは、会話の中身を選んだ接続先に送ります。** 送るのは次のものです。

- 会話の履歴(古いものから切り詰める)
- 今の生成フォームの値(プロバイダー、モデル、操作、プロンプト、パラメーター、入力画像の ID)と、スタジオの結果エリアに出ている画像の ID、ストックで選んでいる画像の ID
- 添付した画像と、アシスタントが見た画像(プレビューを長辺 1024px に縮めた JPEG。原本は送らない)
- プロンプトセットの名前と中身(アシスタントが読んだとき)
- ストックを探した結果(画像の ID、タイトル、タグ、生成したときのプロンプトとモデルなどの文字。アシスタントが探したとき)

### 画像を送る前の許可

アシスタントが道具で画像を見ようとしたとき(「画像を見る」「生成結果を見る」)は、送る前に許可のカードを出します。カードには送る画像のサムネイルと、送り先の接続先の名前が出ます。

- **1度だけ許可:** その呼び出しの画像だけを送ります。次に見ようとしたときも、また聞きます。
- **常に許可:** 以後は聞かずに送ります。ユーザー設定の「表示」にある「アシスタント」の「画像を LLM に送る前に確かめる」をオンに戻すと、また聞くようになります。
- **許可しない:** 画像を送りません。アシスタントは文字の情報(タイトル、タグ、プロンプトなど)だけで続けます。

答えないまま 10 分過ぎたとき、止めるボタンを押したとき、接続が切れたときは「許可しない」と同じです。答えは会話に残り、開き直したカードに出ます。自分で添付した画像は、添付の操作を許可とみなし、聞きません。

### X 以上の画像

アシスタントの接続先が **外部**(LLM の接続先の設定の「接続先」。ADR-0051)のとき、レーティングの段階が X・XX・XXX の画像は、ID、種類、段階、グループだけを送ります。タイトル、タグ、プロンプト、パラメーター、画像は送りません。人が選んだ段階を優先します。

- 検索、似た画像、画像の情報、生成結果、履歴のプロンプト、グループの画像、見つけた画像のカード、整理の結果のすべてに効きます。タグの一覧の件数とグループの提案の特徴的なタグは、X 以上の画像を数えずに作ります。
- 画像を見る道具は、X 以上の画像を送らず、許可も聞きません。添付した X 以上の画像も送らず、発言の添付に「送っていません」と出します。
- タグやグループの整理は画像の ID で働くので、X 以上の画像も中身を送らずに整理できます。
- 接続先が **ローカル** なら、この絞り込みはしません(許可のカードと Mod の送る前のチェックはそのまま効きます)。
- **レーティングの判定を使っていないと、この絞り込みは効きません。** 判定していない画像は段階が分からないので、対象にしません(`docs/content-rating.md`)。

### 結果の大きさ

道具の結果は、1回につき 20,000 字までを送ります。一覧を返す道具(検索、似た画像、履歴、タグの一覧、グループの画像)は、この大きさに収まる件数で打ち切り、返した件数、全体の件数(分かるとき)、続きの位置(`next_offset`)を返します。アシスタントは `offset` で続きを読みます。書き込む前に続きを全部読み、対象の件数と書き込んだ件数が違えば理由を伝えるよう指示しています。

- 一覧の1件は、ID、種類、タイトル、タグ(人が付けたものを先に最大 12 個)、段階、グループの名前だけにします。幅・高さ・作成日時・タグの出どころは「画像の情報」だけが返します。
- サムネイルの焦点、グループの表紙や並び順など、画面のカードだけに使う値は送りません。
- 同じ会話で、直近 3 件より前の道具の結果のうち 2,000 字を超えるものは、画像の ID と件数だけに短くして送ります(保存した結果はそのままです)。

## 書き込みと元に戻す

- アシスタントは、確認を挟まずにプロンプトセットを作成・編集します。削除はしません(ストックの整理は「ストックの整理」を参照)。
- 書き込むたびにカードが出ます。カードの「元に戻す」で変更前に戻せます。作ったセットを元に戻すと、そのセットは削除されます。
- その後に、画面や別の会話で同じセットや項目を変えていた場合は、戻せません。

## 生成

- アシスタントは、確認を挟まずに生成・Edit を実行します。**生成は画像の API の課金になります。**
- 指定の無い項目は、今の生成フォームの値を使います。「今の設定で」と頼めば、フォームの設定のまま生成します。
- アシスタントが作った Run は、実行者が会話の利用者、実行元が「アシスタント」になります。履歴と Run の詳細に「アシスタント」と表示します。
- 作った Run はパネルにカードで並びます。サムネイルを選ぶと、スタジオの結果エリアに表示します。
- 「止める」を押すと、アシスタントを止めます。その発言で作った Run のうち、まだ待っているものは取り消します。実行中の Run は、そのまま最後まで実行します。

## 生成フォームの書き込み

「安いモデルにして」「この画像を入力にして」「縦長にして」のように頼むと、アシスタントが生成フォームの値を書き換えます(ADR-0048 11章)。

- 書き換えられるのは、プロバイダーとモデル、プロンプト(置き換え)、パラメーター(頼んだ項目だけ。既定に戻すこともできる)、入力画像(置き換え。空にもできる)、出力を入れるグループです。頼んでいない項目は変えません。
- 確認は挟まずにフォームに入ります。**書き換えるのはブラウザのフォームだけです。** サーバーにはフォームの値を保存しません。
- 書き換えるたびに「フォームを変更」のカードが出ます。変えた項目の変更前と変更後(入力画像はサムネイル、長いプロンプトは省略)を示します。
- カードの「元に戻す」で、書き換える直前のフォームの値に戻します。その後に続けて書き換えた分も含めて、その時点の値に戻ります。
- 変更前の値は、そのページを開いている間だけ持ちます。ページを読み込み直したときや、会話を開き直したときのカードには、変更後だけを出し、「元に戻す」は出しません。会話を開き直しても、昔の書き換えをフォームに入れ直すことはしません。
- スタジオ以外の画面を開いているときに書き換えた場合は、次にスタジオを開いたときにフォームに入ります。
- アシスタントが生成するとき、指定の無い項目には書き換えた後のフォームの値を使います。
- 使えないプロバイダーやモデル、そのモデルに無いパラメーター、見えない画像やグループを指定した場合は、何も変えずに、アシスタントがその旨を伝えます。値の範囲の細かい確かめは、フォームと生成のときに行います。モデルを変えて使えなくなったパラメーターは、未指定に戻ります。

## 生成結果を直す

結果がいまいちなときは、スタジオの結果エリアに出したまま「顔が崩れている」「もっと明るく」「直すプロンプトを作って」のように頼めます(ADR-0048 12章)。

- 送信のたびに、ブラウザは結果エリアに出ている画像の ID を送ります。結果エリアが空のとき、実行中のとき、スタジオ以外の画面を開いているときは送りません。サーバーには保存しません。
- アシスタントは、道具 `view_result`(パネルでは「生成結果を見る」)で、その画像(縮めたプレビュー)と、タイトル、タグ(自動タグを含む)、生成したときのプロンプト・モデル・パラメーター、主たる親を読みます。ほかの画像を指して読むこともできます(見える範囲は画面と同じ)。
- 読んだ上で、直す点(と保つ点)だけを書いた Edit のプロンプトを、プロンプトのカードで示します。頼めば、結果の画像を入力画像にして、フォームにプロンプトを入れます(「生成フォームの書き込み」)。
- 結果エリアに画像が無いときは、アシスタントがその旨を伝えます。
- 接続先のモデルが画像を読めないときは、接続先のエラーがそのまま出ます。その後は、画像を送らずにタグとプロンプトだけから考えるよう頼めます。

### 前の結果を参照する

「二つ前の結果」「さっきのほうが良かった」「前の2枚を比べて」のように、結果エリアに出ていない前の結果も指せます。

- アシスタントは、道具 `list_recent_results`(パネルでは「履歴を見る」)で、あなたの Run を新しい順に見ます(既定 10 件、最大 50 件。グループでも絞れます)。画面・アシスタント・MCP のどこで作った Run も含みます。見える範囲は履歴の画面と同じです。読むのは文字(日時、状態、モデル、プロンプト、出力と入力の画像の ID)だけで、画像は読みません。
- 対象を決めたら、`view_result` で最大4枚の画像を一度に見て、並べて比べます。
- 「何個前」は Run の単位で数えます。1回で複数枚を出した Run も1つと数えます。結果エリアの画像の Run を起点にすることもあります。アシスタント自身が作った Run も数に入ります。どれを指すか曖昧なときは、候補をカードで示して確かめます。

## ストックの捜索

「夕方の海の画像を探して」「この画像に似たものを集めて」「このグループで、猫が写っているもの」のように頼めます。読み取りだけで、ストックは変えず、生成の課金もありません。

- アシスタントは、まず検索の道具の文字の情報で探します。検索の方式は3つです。
  - **hybrid(既定):** 文字での検索と、画像の埋め込みで意味の近い画像を探す検索(`docs/embeddings.md`)を組み合わせ、1つの順位にします(Reciprocal Rank Fusion。それぞれの順位から `1/(60+順位)` を足す)。結果の各件に、どちらで当たったか(文字、意味、両方)が付きます。
  - **keyword:** プロンプト・タイトル・タグの文字で探します(新しい順)。言葉が正確に分かっているときに使います。
  - **semantic:** 画像の埋め込みで、説明に見た目の近い画像を探します。
- グループ、タグ、画像の種類で絞り込めます。1回に返すのは 50 件までで、続きは `offset` で読みます(語で探すときは先頭から 500 件まで)。グループの画像は「グループの画像を読む」で全部読めます。
- 文字では決められないときだけ、絞った少数の画像を見ます(縮めたプレビューを接続先に送ります。送る前に許可を求めます)。合うものだけをカードで示します。
- 見える範囲は、画面と同じです(ADR-0025)。ログインを有効にしている場合、他の人の画像は出ません。
- **埋め込みが無効のとき**(管理者設定の「画像の埋め込み」が無効、または使えるモデルが無いとき)は、意味で探すことと似た画像を探すことはできません。既定の hybrid は文字での検索に切り替え、結果にその旨を入れます。semantic を指定したときと似た画像を探すときはエラーになり、アシスタントは文字での検索に切り替えるか、その旨を伝えます。
- 探している途中の呼び出しは、他の道具と同じく折りたたみの行で出ます。カードになるのは、アシスタントが「画像を示す」で示した画像だけです。

見つけた画像のカードでは、次の操作ができます。

- サムネイルを選ぶと、スタジオの結果エリアに表示します。
- サムネイルを生成フォームの入力画像の欄へドラッグすると、入力に使えます。
- 「すべて添付」で、カードの画像を次の発言の添付に入れます。添付は 4 枚までで、入りきらない分と、すでに添付している画像は入れません(その旨をカードに出します)。
- 見つけた画像を生成の入力にするよう頼めば、アシスタントがそのまま生成・Edit に使います。

## ストックの整理

「選んだ画像に『背景』のタグを付けて」「未整理の画像をグループに分けて」「この似た画像をまとめて新しいグループにして」のように頼めます(ADR-0048 13章)。

- できること: タグを付ける・外す、タイトルを変える(空にもできる)、グループを作る・名前を変える、グループに入れる・グループから外す。画像とグループは削除しません。
- 画像の所属は 1 つのグループだけなので、グループに入れると元のグループからは外れます(ADR-0022)。
- 1 回の操作で扱えるのは 200 枚までです。それより多いときは、アシスタントが分けて操作します。
- 見える範囲と書き込める範囲は画面と同じです(ADR-0025)。ログインを有効にしている場合、他の人の画像とグループは変えられません。
- 確認は挟まずに書き込みます。ただし、対象が曖昧なとき(「未整理の画像」が何を指すか分からないなど)は、書き込む前に対象と枚数を示して確かめます。タグの名前は、すでにあるタグに合わせます。
- **人の編集と同じ扱いです。** アシスタントが付けたタグとタイトルは、画面で人が付けたものと見分けられず、自動のタイトル・タグの再推定(`docs/auto-tags.md`)で上書きされません。外したタグも、再推定で付け直されません。誤りは「元に戻す」か画面の編集で直します。

### 選んだ画像

ストックの「選択」で画像を選んでから頼むと、アシスタントは「選んだ画像」をその画像だと分かります。送信のたびに、ブラウザは選んでいる画像の ID(200 枚まで)を送ります。選んでいなければ送りません。サーバーには保存しません。

### 整理の結果と元に戻す

- 書き込むたびに、整理の結果のカードが出ます。操作、タグやグループの名前、枚数、サムネイルの一部(12 枚まで)を示します。サムネイルを選ぶと、スタジオの結果エリアに表示します。
- 書き込んだ後は、ストックとグループの一覧、画像のタグとタイトルを読み直します。
- カードの「元に戻す」で、画像ごとに書き込む前の状態に戻します。
  - タグは、付いていなかったタグは外し、自動で付いていたタグは自動のタグ(確信度も)に戻し、人が外していたタグは外した状態に戻します。
  - タイトルは、元のタイトルとその出どころ(自動・人)に戻します。
  - グループは、元のグループ(または「グループなし」)に戻します。作ったグループを元に戻すと、画像を元に戻してからグループを削除します。ほかの画像がその後に入っていれば、グループは残します。
- 戻すのは、書き込んだ後に変わっていない画像だけです。画面や別の会話で変えた画像は戻さず、戻した枚数と戻さなかった枚数をカードに出します。すべて変わっていたときは戻せません。

### グループの提案

アシスタントは、グループの提案(ADR-0056、ストックの「⋯」の「グループの提案」と同じもの)を読んで、振り分けの案にできます。提案を見るだけでは何も保存しません。画像の埋め込みが無効のときは使えないので、アシスタントはその旨を伝えます。

### 確認用のダミーのエンジン

`FAKE_PROVIDER=1` のダミーのエンジンでは、発言の行に `/tool 道具の名前 {引数の JSON}` と書くと、その道具を呼びます。たとえば `/tool add_tags {"asset_ids": ["<画像の ID>"], "tags": ["sea"]}`、`/tool suggest_groups {}`。

## 会話

- 会話はサーバーに保存します。ログインを有効にしている場合、見えるのは本人の会話だけです(ADR-0025)。
- 会話は、パネルの上部で切り替え、名前を変え、削除できます。
- 送信は Ctrl+Enter(macOS は Cmd+Enter)です。Enter は改行です。
