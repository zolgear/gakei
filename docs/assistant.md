# 生成のアシスタント

右のサイドバーの「アシスタント」パネルで、チャットでアシスタントに頼みごとができます(ADR-0048)。

- プロンプトを作る・直す・訳す。作ったプロンプトはカードで示し、「フォームに入れる」「フォームを置き換える」「コピー」のボタンでフォームに入れます。
- プロンプトセットを読む・作る・編集する。
- 添付したストックの画像を見て、プロンプトを作る。
- 生成・Edit を実行し、結果を見て次を作る。たとえば「雰囲気の違う画像を3枚」や、「三面図を、正面から1枚ずつ」のような作業です。

既定では無効です。管理者設定の「アシスタント」(`/settings/assistant`)で有効にします。

## 設定

管理者設定の「アシスタント」で、次を決めます。変えた値は、ページ上部の「保存」を押すまで反映されません(ADR-0031)。

| 項目 | 内容 | 既定 |
|---|---|---|
| 有効 | パネルを出し、発言を受け付ける | 無効 |
| 接続先 | 「LLM の接続先」(`/settings/llm-connections`)で登録した接続先から選ぶ | OpenAI の設定 |
| モデル | 接続先のモデル名。道具の呼び出し(tool calling)に対応したモデルが要る。画像を添付するなら、画像入力にも対応したモデルにする | `gpt-5.6-luna` |
| LLM の 1 時間の上限 | 利用者ごとの、LLM へのリクエストの回数 | 200 |
| 1 回の発言の Run の上限 | 1 回の発言で作れる Run の数 | 20 |
| 1 時間の Run の上限 | 利用者ごとに、アシスタントが作れる Run の数。0 にすると生成を止める | 60 |

- 1 回の発言で、アシスタントが道具を呼べるのは 40 回までです。
- LLM の 1 時間の上限はプロセスの中で数えるので、再起動すると 0 に戻ります。Run の上限は、実行元がアシスタントの Run を DB で数えます。
- 上限に達すると、アシスタントは Run を作らずに、その旨を伝えます。

### 接続先の API 形式

接続先の API 形式(Responses / Chat Completions)は、「LLM の接続先」で選びます。

- **OpenAI 本体には Responses を使います。** OpenAI の推論モデル(gpt-5.6 や GPT-6 系など)は、Chat Completions では、推論を切ったとき(`reasoning_effort: "none"`)しか道具を使えません。Chat Completions を選んだ場合、GAKEI はこの断りを受けたときに推論を切って送り直します。その分、応答の質が下がることがあります。
- **ローカルの LLM(vLLM、llama.cpp、Ollama など)には Chat Completions を使います。** Qwen3 などの道具の呼び出しは、これらのサーバーの `/v1/chat/completions` で動きます。サーバー側で、道具の呼び出しを有効にしておきます(vLLM ではツール呼び出しのパーサーの指定、llama.cpp では `--jinja`)。

## 送るもの

**アシスタントは、会話の中身を選んだ接続先に送ります。** 送るのは次のものです。

- 会話の履歴(古いものから切り詰める)
- 今の生成フォームの値(プロバイダー、モデル、操作、プロンプト、パラメーター、入力画像の ID)
- 添付した画像と、アシスタントが見た画像(プレビューを長辺 1024px に縮めた JPEG。原本は送らない)
- プロンプトセットの名前と中身(アシスタントが読んだとき)

## 書き込みと元に戻す

- アシスタントは、確認を挟まずにプロンプトセットを作成・編集します。削除はしません。
- 書き込むたびにカードが出ます。カードの「元に戻す」で変更前に戻せます。作ったセットを元に戻すと、そのセットは削除されます。
- その後に、画面や別の会話で同じセットや項目を変えていた場合は、戻せません。

## 生成

- アシスタントは、確認を挟まずに生成・Edit を実行します。**生成は画像の API の課金になります。**
- 指定の無い項目は、今の生成フォームの値を使います。「今の設定で」と頼めば、フォームの設定のまま生成します。
- アシスタントが作った Run は、実行者が会話の利用者、実行元が「アシスタント」になります。履歴と Run の詳細に「アシスタント」と表示します。
- 作った Run はパネルにカードで並びます。サムネイルを選ぶと、スタジオの結果エリアに表示します。
- 「止める」を押すと、アシスタントを止めます。その発言で作った Run のうち、まだ待っているものは取り消します。実行中の Run は、そのまま最後まで実行します。

## 会話

- 会話はサーバーに保存します。ログインを有効にしている場合、見えるのは本人の会話だけです(ADR-0025)。
- 会話は、パネルの上部で切り替え、名前を変え、削除できます。
- 送信は Ctrl+Enter(macOS は Cmd+Enter)です。Enter は改行です。
