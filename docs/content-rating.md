# レーティング(判定とマスク)

GAKEI は、画像を WD Tagger で判定してレーティングを付け、選んだ段階の画像を履歴やストックでぼかして見せられます(ADR-0049)。

## 段階

| 段階 | 目安 |
|---|---|
| グリーン | 性的な表現が無い |
| R | 水着、下着、胸の谷間など |
| X | 部分的な露出 |
| XX | 露骨な表現(性器など) |
| XXX | XX に加えて、性行為を示すもの |

暴力や流血は判定の対象にしません。

## 判定のしかた

- WD Tagger v3 の rating の4つの確率(general、sensitive、questionable、explicit)から基準の段階を決めます。強い側から確率を足して 0.5 以上になった段階を選びます。
- 一般タグ(水着、nude、性器、性行為など)の確率が高ければ、段階を引き上げます。下げることはありません。XXX へは、それまでの段階が XX 以上のときだけ上げます。
- 規則(タグの表としきい値)はコードの `backend/app/domain/content_rating.py` にあり、版を持ちます。設定画面では変えられません。
- 判定は GAKEI の中で行い、画像をどこにも送りません。WD Tagger はイラスト向けで、写真には向きません。

## 有効にする

1. 管理者設定の「自動タイトル・タグ」で、WD Tagger のモデルをダウンロードします([auto-tags.md](auto-tags.md))。タグ付け(ONNX タガー)を有効にしていなくても判定はできます。使うモデルは ONNX タガーで選んだものです。
2. 同じページの「レーティング」で「レーティングを判定する」をオンにして保存します。
3. 既にある画像は「まとめて判定する」で判定します。未判定の画像と、古い版の規則で判定した画像が対象です。

オンにすると、生成・アップロード・スケッチの取り込みのたびに判定します(自動タイトル・タグの「取り込み時に自動で推定する」とは別に、常に)。判定は WD の推論1回分の CPU を使います。タイトル・タグの推定で ONNX タガーが走るときは、同じ推論の結果から判定します。

判定が済むまでの数秒は未判定として扱います。既定では未判定の画像はマスクしません。

## 判定を見る・直す

画像ビューアの情報欄の「レーティング」(タグの節の下)で、段階と、自動か人が選んだかを確かめられます。

- 「詳しく見る」で、rating の4つの確率、段階を上げたタグ、モデル、規則の版、判定の時刻が見えます。
- 段階のボタンで人が段階を選べます。人が選んだ段階は、再判定しても変わりません。「自動に戻す」で自動の段階に戻ります。
- 「再判定」で判定し直します。

## マスク

ユーザー設定の「表示」→「レーティングのマスク」で、ぼかす段階を選びます。既定は R 以上です。「未判定もマスクする」を選ぶと、判定の済んでいない画像もぼかします。

- この設定はサーバーに保存され、どの端末でも同じです。ログインを有効にしている場合はユーザーごとです。
- ぼかした画像をクリックすると、その画像だけ見えます。ページを読み直すと戻ります。ビューアでは「表示する」を押します。
- 見えるようにした画像の隅には、目を閉じたアイコンと段階が出ます。押すと、その画像をまたぼかします。ビューアと比較では、画像の右下の「マスクする」を押します。
- 履歴、作業場、ストック、ビューア、検索、重複、系列、比較、アシスタントの画像カード、マップでぼかします。共有リンクの公開ページではぼかしません。

### マップ

マップでも、同じ設定の段階の画像をぼかして描きます。大きく描いているときは、段階も重ねて出します。選んだ画像のカードと、大きく見るパネルの画像もぼかします。

- マップでは1枚ずつは見えるようにしません。画像を押すと、今までどおり選択になります。
- 上部の目のボタンで、マップ全体のぼかしを外す・掛けるを切り替えます。マップにぼかす画像が無いときは、ボタンは出ません。
- 切り替えはページを読み直すと戻ります。マップで外しても、履歴などで1枚ずつ見えるようにした状態は変わりません。

**マスクは表示のためのもので、アクセスの制限ではありません。** ぼかす前の画像もブラウザに届いていて、画像の URL を開けばそのまま見えます。人に見せたくない画像を守る手段としては使えません。

## API と MCP

- 一覧と詳細の応答に `content_rating`(`g`、`r`、`x`、`xx`、`xxx`、未判定は `null`)が付きます。
- MCP とアシスタントの検索・画像の情報にも `content_rating` が付きます。AI に渡す画像はぼかしません。
