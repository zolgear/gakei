# タイトルとタグ(自動推定)

GAKEI では画像にタイトルとタグを付けて、ストックや検索で探せます。タイトルとタグは画像ビューアの情報欄で付けたり直したりでき、自動で推定させることもできます(ADR-0024)。

## 自動と人の区別

- 自動で付いたタグは点線の枠で、人が付けたタグは塗りつぶしで表示します。自動で付いたタイトルは控えめな色で表示します。
- 人が直したタイトルや、人が外したタグは、再推定しても上書きしません。
- ログインを有効にしている場合、タイトルとタグを見たり直したりできるのは、その画像が見える本人だけです。タグの一覧と件数も、本人の画像だけで数えます(ADR-0025)。

## エンジン

管理者設定の「自動タイトル・タグ」で、使うエンジンを選びます。どれも既定では無効です。

| エンジン | 付けるもの | 送信先 | 費用 |
|---|---|---|---|
| LLM | タイトル(プロンプトから推測) | OpenAI 互換 API | 呼び出しごとに課金(安い) |
| VLM | タグ。プロンプトの無い画像ではタイトルも | OpenAI 互換 API | 呼び出しごとに課金 |
| ONNX タガー(WD Tagger v3) | タグ(英語) | どこにも送らない(GAKEI の中で推定) | 無料 |

- **LLM と VLM は、プロンプトや画像を外部の API に送ります。** 接続先は OpenAI の設定をそのまま使います。推定専用の接続先(Base URL)とキーを指定すれば、Ollama や LM Studio など手元の OpenAI 互換サーバーも使えます。手元のサーバーが Responses API に対応していないときは、API 形式で Chat Completions を選びます。
- VLM に使うモデルは、画像入力に対応している必要があります。
- LLM と VLM の呼び出しには 1 時間あたりの上限があります(既定 100 回)。上限に達した推定は失敗にならず、次の枠まで待ちます。
- **ONNX タガー**は SmilingWolf の WD Tagger v3(Apache-2.0)です。イラスト向けで、写真には向きません。モデル(約 380MB〜1.3GB)は配布物に含まれていないので、設定画面のボタンで Hugging Face からダウンロードします。ダウンロードしたモデルは `DATA_DIR/models/` に保存されます。

### ONNX タガーのモデルとメモリ

| モデル | ダウンロード | メモリ目安 | 1 枚の推定(参考) |
|---|---|---|---|
| wd-vit-tagger-v3(Base、既定) | 約 380MB | 約 0.7 GB | 約 3.5 秒 |
| wd-swinv2-tagger-v3(Base) | 約 470MB | 約 0.8 GB | 約 4 秒 |
| wd-eva02-large-tagger-v3(Large) | 約 1.3GB | 約 1.6 GB | 約 17 秒 |

- **GPU の無い環境では wd-swinv2-tagger-v3(Base)を推奨します。** wd-eva02-large-tagger-v3 は読み込みに多くのメモリを使い、1 枚の推定にも数倍の時間がかかります。
- メモリ目安は、モデルを読み込んで 1 枚推定したときに GAKEI のプロセスが使うメモリの最大値です(Raspberry Pi 5、aarch64、4 コアでの実測を切り上げた値)。推定の時間も同じ機械での値で、CPU によって変わります。GAKEI 本体と OS の分は別に要ります。
- 推定の前に空きメモリ(Linux の MemAvailable。コンテナではメモリ上限の残りも)を確かめ、目安より少なければモデルを読み込まずに、その画像の推定を失敗にします。メモリ不足でプロセスが落ちて、再起動のたびに同じモデルを読み込んでまた落ちる、という繰り返しを防ぐためです。Windows と macOS では確かめません。
- 読み込んだモデルは、10 分使わなければメモリから解放します。

## タグの言語

管理者設定の「タグの言語」で選びます。

- **タイトルとタグの言語に合わせる(既定):** VLM は設定した言語でタグを付けます。ONNX タガーの英語のタグはそのまま残し、その訳もタグとして足します(言語が英語のときは訳しません)。訳は、VLM が有効なら同じ呼び出しで作り、VLM が無効で LLM が有効なら LLM で作ります(この呼び出しも 1 時間の上限に数えます)。どちらも無効なら訳しません。
- **エンジン任せ:** 各エンジンがそれぞれの言語でタグを付けます。ONNX タガーのタグは英語のままで、訳しません。

どちらの場合も、VLM には ONNX タガーのタグを渡し、同じ意味のタグを付け直さないよう頼みます。タグとタイトルは利用者のデータなので、画面の言語を切り替えても変わりません。

## 実行のタイミング

- **取り込み時に自動:** 設定でオンにすると、生成・アップロード・スケッチのたびに推定します。既定はオフです。
- **一括実行:** 管理者設定から、まだ推定していない画像をまとめて推定します。
- **1 枚ずつ:** 画像ビューアの「再推定」ボタンで推定します。
