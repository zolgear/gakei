# IP 素材

自社や他社から預かった版権の素材(IP 素材)を、許可したチーム・人だけが、許可した用途にだけ使えるようにする機能です。使ったことは記録に残り、権利者への報告に使えます。設計は ADR-0058(チーム)、ADR-0059(IP 素材)、ADR-0060(ロック)にあります。

## 使える条件

- 認証モード(OIDC)で動かしていること(`docs/auth.md`)。個人モードでは、誰が使ったかを示せないので使えません。
- 管理者設定の「IP 素材」で「IP 素材を使う」をオンにすること(既定はオフ)。

オフに戻しても、取り込んだ素材の記録と、素材から作った画像の制限は残ります。

## 役割

| 役割 | できること |
|---|---|
| 管理者 | 機能の有効・無効。IP を作る・名前と状態(有効・停止・終了)を変える。担当者を決める。チームを作り、代表者を決める |
| IP の担当者 | その IP の素材の取り込みと取り下げ、契約の条件の版、許可を出す・取り消す、証跡を見る |
| チームの代表者 | 自分のチームのメンバーを出し入れする |
| 許可を受けた人 | 素材を見る(許可によっては入力に使う) |

## 流れ

1. 管理者が「チーム」(管理者設定)でチームを作り、代表者とメンバーを決めます。
2. 管理者が「IP 素材」(管理者設定)で IP を作ります。名前、自社か他社か、権利者、最初の契約の条件(契約番号、期間、許諾された用途、外部の AI への送信、注記)を入れます。
3. 管理者が IP のページの「担当者」で担当者を決めます。
4. 担当者が「素材」で素材を取り込みます。素材は普段のストックには出ず、IP の棚(アイコンレールの盾のアイコン)に出ます。
5. 担当者が「許可」で、チームか個人に、許す用途と「入力に使えるか」を選んで許可を出します。期間も決められます。

## 使うとき

- IP 素材か、それから作った画像(派生物)を入力にすると、生成のフォームの送るボタンの近くに申告の欄が出ます。IP の名前と契約の注記を確かめ、用途を選んでから送ります。作業のメモ(案件や発注など)は自由に書けます(任意)。
- 送るときと、実行する直前の2回、許可・用途・契約の期間・送り先を確かめます。合わなければ送らず、断ったことを記録します。
- 派生物は、作った人と、同じ IP の許可を持つ人(チームのメンバーなど)に見え、許可の用途で入力にも使えます。IP の担当者は、ほかの IP が混ざったものも含めて、その IP の派生物をすべて見られます(IP のページの「派生物」)。
- IP 素材と派生物は、共有リンクにできません。系列の書き出しはできますが、記録に残ります。
- MCP から生成するときは、`ip_purpose`(用途)と `ip_work_note`(作業のメモ)を渡します。

## 契約の条件

- 条件を変えるときは「条件を改める」で新しい版を作ります。古い版は残り、いつどの条件だったかを後から示せます。
- 外部の AI への送信は3つから選びます。
  - 許可: 外部の接続先にも送れます。
  - 手元の接続先だけ: 管理者設定で「ローカル」とした接続先(ADR-0051 の接続先の区分)にだけ送ります。
  - どの AI にも送らない: 画像の生成・編集の入力にも、自動タイトル・タグや埋め込みにも使いません。
- 「許可」でない素材とその派生物は、自動タイトル・タグ、埋め込み、領域の検出、アシスタントへの添付に使いません(手元の接続先でも、今は使いません)。取り込みのときに Mod にも渡しません。

## 記録

- 証跡(IP のページの「証跡」)には、IP と条件の変更、素材の取り込みと取り下げ、許可の追加と取り消し、素材の詳細を開いたこと、原本を取得したことが残ります。
- 原本のダウンロードは止めません。画面に表示できるものは写しなどで持ち出せるので、止めずに記録します。
- 証跡は書き換えも削除もできません。

## 状態

- 停止: 許可がすべて一時的に効かなくなります。再開できます。
- 終了: 許可がすべて効かなくなり、戻せません。
