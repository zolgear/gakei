# 共有リンク(ログイン不要)

生成した画像を、プロンプトやパラメーター、どの画像から Edit したか(系列)ごと、ログインしていない人に見せるための機能。リンク(`/s/{トークン}`)を知っている人は誰でも見られる。設計は [ADR-0029](adr/0029-public-share-links.md)。

同じ GAKEI の利用者どうしで見せ合う機能ではない(認証モードでは、利用者は本人の画像だけを見る。ADR-0025)。

## 1. 有効にする

既定では無効になっている。管理者が設定画面の「管理者設定」→「共有リンク」で有効にする。

- 無効のあいだは、共有を作る操作が画面に出ず、既存の共有リンクもすべて開けなくなる(404)。ユーザー設定の「共有リンク」(自分の共有の一覧)も出ない。共有の記録は消えないので、有効に戻せば、取り消していないリンクはまた開け、一覧と取り消しもできる。
- **個人モード(`AUTH_MODE=none`)で使う場合は、「4. 個人モードで外に出す」を必ず読むこと。** 個人モードには認証が無いので、サーバーをそのままインターネットに出すと、共有していない画像も含めて全部が見える。

リンクの URL は `{PUBLIC_BASE_URL}/s/{トークン}`。`PUBLIC_BASE_URL` が無ければ、共有を作ったときにブラウザで開いていた URL(例 `http://127.0.0.1:8000`)から組み立てる。外の人に渡すリンクを外から開ける URL にしたいときは、`PUBLIC_BASE_URL` に外から開く URL(例 `https://share.example.com`)を設定する([configuration.md](configuration.md))。

## 2. 共有する

1. ビューア(画像を開いた画面)で「共有」を押す。
2. 範囲を選ぶ。
   | 範囲 | 含まれる画像 |
   |---|---|
   | この1枚 | その画像だけ |
   | 祖先まで | その画像と、Edit の元になった画像を親の方向にさかのぼったもの(入力に使ったマスクや参照画像も含む) |
   | 祖先と子孫 | 上に加えて、その画像から作った画像(子の方向) |
3. 「原本の表示とダウンロードを許す」を選ぶ(既定はオン)。オフにすると、見る人はプレビュー(長辺 2048px)までしか見られない。
4. 含まれる画像の枚数とサムネイルが出るので、外に出してよいものか確かめてから「リンクを作る」を押す。
5. 出てきたリンクをコピーして相手に渡す。

- 範囲は、共有を作った時点で固定する。そのあとに作った子孫は、自動では載らない(載せたければ、新しく共有を作る)。
- 同じ画像から、範囲や原本の可否の違う共有をいくつでも作れる。
- 系列は、共有する人から見える画像だけでたどる。アップロードした PNG に埋め込まれていた系列(ADR-0014 の「埋め込み」)や、別の GAKEI の画像は含めない。同じ Run が作った兄弟の画像(`n` を 2 以上にしたときの別の出力)も、祖先でも子孫でもないので含めない。
- 有効期限は無い。取り消すまで有効。

### 共有のページで見られること

- 左のビューアで画像をパン・ズームして見る。右のパネルに、画像のタイトル、作成日時、その画像を作った Run のプロンプトとパラメーターが出る。
- 範囲が「祖先まで」「祖先と子孫」なら、パネルの下に系列グラフが出る(通常の画面と同じく、主たる親は実線、参照やマスクは破線)。画像のノードを押すとその画像を開き、Generated(Run)のノードを押すと、パネルがその Run の詳細に切り替わる。画像の情報の「Generated 詳細を見る」からも開ける。
- Run の詳細には、プロンプト、最終プロンプト(ComfyUI で Prompt Enhancer などが実行時に作ったプロンプト。ADR-0030)、操作(生成/編集)、モデル、パラメーター、作成日時と、入力・出力のサムネイルが出る。入力は「主たる親」と「参照」(マスク、スケッチ、2枚目以降の入力画像)に分けて出す。入力も出力も、共有に含まれる画像だけを出す(範囲外のものは枚数も出さない)。サムネイルを押すと、その画像をビューアで開く。
- Edit の Run で、主たる親と出力の両方が共有に含まれるときは、「編集前と比較する」でビューアの場所に比較を出す(並べて表示・スライダー。狭い幅ではスライダーだけ)。原本を許していない共有では、比較もプレビューまで。
- Run の詳細を開いているあいだは、URL が `/s/{トークン}/runs/{run_id}` になり、このリンクで直接開ける。共有に含まれない Run(失敗・取り消しの Run を含む)の URL は、ほかと同じく「このリンクは無効です」になる。画像を選んでも URL は変わらない(`/s/{トークン}` のまま)。
- 系列グラフの「広げる」で、グラフだけを全画面で見られる(URL は `/s/{トークン}/lineage` で、このリンクで直接開ける)。ノードのサムネイルが大きくなり、開いたときは系列全体が収まる。画像のノードを押すとビューアでその画像を、Generated のノードを押すとその Run の詳細を開く。「ビューアに戻る」で元の表示に戻る。

## 3. 一覧と取り消し

機能が有効のとき、設定画面の「ユーザー設定」→「共有リンク」に、自分が作った共有の件数と「一覧を開く」ボタンが出る。ボタンを押すと、共有の一覧がダイアログで開く(起点の画像、範囲、原本の可否、作成日時、最後に開かれた日時、開かれた回数)。共有が 1 件も無いときは、ボタンは出ない。

- 「リンクをコピー」で、もう一度リンクをコピーできる(トークンは DB にそのまま保存している)。
- 「取り消す」で、そのリンクは開けなくなる。元には戻せない(同じ画像をもう一度共有すると、新しいリンクになる)。
- 見られるのは自分が作った共有だけ。管理者も、他人の共有は見られない・取り消せない。個人モードの頃に作った共有(作成者の記録が無いもの)は、認証モードに切り替えた後は管理者に見える(ADR-0025 と同じ扱い)。
- 共有に含まれる画像をあとで削除すると、共有のページからも消える。起点の画像を削除すると、共有そのものが開けなくなる(一覧には残るので、取り消せる)。
- 機能が無効のあいだは、一覧を出さない(「共有リンク」の項目ごと出ない)。有効に戻せば、一覧と取り消しができる。無効のあいだは、リンクはどれも開けない。

## 見せるもの・見せないもの

見せるもの:

- 画像(サムネイル、プレビュー。原本は共有するときに許した場合だけ)
- 画像のタイトル(ADR-0024)と作成日時
- その画像を作った Run のプロンプト、モデル、操作(生成/編集)、パラメーター(サイズ、品質など)
- 範囲が「祖先まで」「祖先と子孫」なら、含まれる画像どうしの系列グラフ
- Run の詳細(プロンプト、最終プロンプト、操作、モデル、パラメーター、作成日時、共有に含まれる入力・出力)と、Edit の「編集前と比較する」
- ComfyUI の Run のパラメーター(`comfyui_*` を含む。ComfyUI に送ったグラフ全体、入力画像のファイル名、ワークフローの id、使った seed など)。原本を許していない共有でも出す。グラフ全体のような入れ子の値は、畳んだ JSON で出す(2026-10-01 改訂。ComfyUI は原寸の PNG に自分でワークフローを埋め込むので、原寸の画像からも同じ情報が分かる)。ただし、秘密に見える値は伏せる(下の「秘密に見える値」)

見せないもの:

- 実行した人・アップロードした人の名前、メールアドレス、アバター、利用者の id
- 料金と usage、採用/不採用の印、グループ、タグ
- 共有に含まれない画像(グラフの中でも出さない)。Run の入力のうち範囲外の画像も出さない
- 画像に埋め込まれていた、他のツールの生成メタ情報(ADR-0018)
- 失敗した Run、取り消した Run
- ComfyUI 以外の Run のパラメーターのうち、文字列・数値・真偽値でないものと、値に id(UUID)や画像のハッシュ(sha256)を含むもの
- 原本をダウンロードしても、PNG に系列情報(ADR-0014)は埋め込まない

### 秘密に見える値(ComfyUI)

カスタムノードには、API キーなどをノードの入力に直接書くものがある。ComfyUI の Run では、送ったグラフの各ノードの入力と公開パラメーターのうち、秘密に見える値を `***` に置き換えて見せる(入力の名前は残す)。

- 秘密に見えるのは、入力の名前が `api_key`・`token`・`secret`・`password`・`credential`・`authorization`・`bearer`・`access_key`・`private_key` などに当たるもの(`max_tokens` のような別の語は当たらない)と、値がよく知られた API キーの形(`sk-…`、`hf_…`、`ghp_…`、`AKIA…`、`AIza…`、`Bearer …` など)のもの。
- その Run の画像は、共有が原本を許していても**原本を出さない**(プレビューまで。原本のダウンロード、比較の原本への差し替えも無い)。ComfyUI は原寸の PNG に送ったグラフを自分で埋め込むので、原本からは値が読めてしまうため。
- 判定は推測なので、漏れはありうる。キーを入力に直接書くワークフローは、なるべく共有しない。ワークフローを登録するときにも、同じ判定で警告が出る。

共有のページとその API の応答には `X-Robots-Tag: noindex` と `Referrer-Policy: no-referrer` を付ける。画像の `Cache-Control` は `private, max-age=300`(取り消したあとも、見た人のブラウザには最大 5 分残りうる)。

## 4. 個人モードで外に出す

個人モード(`AUTH_MODE=none`)には認証が無い。サーバーをそのままインターネットに出すと、共有していない画像、プロンプト、設定画面(API キーの保存を含む)まで、誰でも操作できてしまう。**外に出すのは、共有のページに要るパスだけにする。** 逆プロキシで、次のパスだけを GAKEI に渡し、それ以外は 404 にする。

| パス | 用途 |
|---|---|
| `/s/*` | 共有のページ(画面) |
| `/api/public/*` | 共有のページの API と画像の配信 |
| `/static/*` | 画面の JavaScript、CSS、フォント |
| `/favicon.ico`、`/favicon.svg`、`/apple-touch-icon.png` | アイコン |

共有のページは `/api/auth/me` などログイン前提の API を呼ばないので、上のパスだけで表示できる(2026-09-30 に Caddy で確かめた)。

GAKEI 自身は、いつもどおり `127.0.0.1` で待ち受けさせる(`HOST` を変えない)。自分で使う画面は、これまでどおり `http://127.0.0.1:8000` で開く。共有リンクの URL を外向けにするため、`PUBLIC_BASE_URL` を外から開く URL にしておく(例 `PUBLIC_BASE_URL=https://share.example.com`。個人モードでは、ほかに MCP の接続先の表示が変わるだけ)。

### Caddy の例

```caddyfile
share.example.com {
	@share path /s/* /api/public/* /static/* /favicon.ico /favicon.svg /apple-touch-icon.png
	handle @share {
		reverse_proxy 127.0.0.1:8000
	}
	handle {
		respond 404
	}
}
```

### nginx の例

```nginx
server {
    listen 443 ssl;
    server_name share.example.com;
    # ssl_certificate などは省略

    location ~ ^/(s|api/public|static)/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location = /favicon.ico          { proxy_pass http://127.0.0.1:8000; }
    location = /favicon.svg          { proxy_pass http://127.0.0.1:8000; }
    location = /apple-touch-icon.png { proxy_pass http://127.0.0.1:8000; }

    location / {
        return 404;
    }
}
```

nginx の例は構文だけで、この環境では動かしていない(Caddy の例と同じパスを渡す)。

認証モード(`AUTH_MODE=oidc`)では、ほかの画面と API はログインが要るので、サーバーをまるごと外に出してもよい(共有のパスだけを分けて出す必要はない)。

## 注意

- リンクが漏れれば、誰でも見られる。見せる相手を限りたい場合は、取り消して作り直す。
- 取り消し・機能の無効化の後も、すでに開いた人のブラウザには、画像が最大 5 分キャッシュに残りうる。保存された画像は消せない。
- MCP(ADR-0023)には、共有を作るツールは無い。外に公開する操作なので、人が画面で行う。
