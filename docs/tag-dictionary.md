# タグ辞書(タグの補完と日本語訳)

管理者がタグ辞書のファイルを登録すると、プロンプトのタグの候補(ADR-0039)を辞書から出し、タグに日本語訳を添えられます(ADR-0041)。日本語で打って英語のタグを出すこともできます。辞書はインスタンス全体で共有し、登録・有効/無効の切り替え・削除は管理者だけができます。

辞書のデータは GAKEI に含まれていません。利用者が用意してください。**配布の条件(ライセンス、再配布の可否)は辞書ごとに違うので、使う前にそれぞれの辞書の条件を確認してください。**

## 辞書の形式

どちらもヘッダーなしの CSV(UTF-8。BOM があってもよい。改行は LF でも CRLF でもよい)です。種類は列の数で判定します。

| 種類 | 列 | 例 |
|---|---|---|
| タグの一覧 | 4 列: タグ名, カテゴリー, 件数, 別名 | `long_hair,0,1234567.0,"longhair,ロングヘア"` |
| 訳 | 2 列: タグ名, 訳 | `cat_ears,"猫耳,ねこみみ"` |

- タグ名は `_` 区切りのまま書きます(候補では `_` を空白にして出します)。
- 件数は整数でも小数表記(`1234.0`)でもかまいません。別名(タグの一覧)と訳は、1 つの欄にカンマ区切りで複数書けます(引用符で囲む)。訳は先頭が代表です。
- 別名の列が無い 3 列のファイルも、タグの一覧として読みます。
- カテゴリーの番号は、登録時に選ぶ「カテゴリーの体系」で解釈します。`danbooru` は 0 一般、1 作者、3 作品、4 キャラクター、5 メタです。ほかのサイトの辞書は番号の意味が違うので `other` を選びます(番号のまま扱います)。
- 先頭の数百行の多数決で種類を決めます。読めない行が 1 割を超えるファイルは登録できません。読めない行は飛ばして取り込みます。同じタグが何度も出てくるときは、最初の行を使います。

CSV をまとめた zip も登録できます。zip の中の CSV だけを読み(ほかのファイルは無視)、CSV ごとに辞書を作ります。展開した合計は 100MB まで、CSV は 16 個まで、パスワード付きの zip は読めません。アップロードできるファイルは 100MB までです。

## 登録と取り込み

- 管理者設定の「タグ辞書」で、ファイルを選んで登録します。API は `POST /api/settings/tag-dictionaries`(multipart の `file`、任意で `category_scheme`)です。
- アップロードしたファイルそのものは保存しません。中身は DB のテーブルに取り込みます(SQLite でも PostgreSQL でも同じ)。
- 取り込みは登録の後にサーバーの中で行います。数十万行の辞書では十数秒〜数十秒かかります。その間は「取り込み中」と表示し、候補と訳には前から登録していた辞書を使います。取り込み中にサーバーを止めると、次の起動で「失敗」になります。もう一度登録してください。
- 取り込み中の辞書は削除できません。

## 使われ方

- **候補:** 有効なタグの一覧の辞書があれば、候補は辞書から出します(WD Tagger の語彙と GAKEI のタグは使いません)。順は、タグ名の前方一致、別名の前方一致、訳の前方一致、訳の部分一致で、同じ段の中は件数の多い順です。最大 20 件。複数の辞書を有効にしていれば合わせて使い、同じタグは件数の多い方を出します。
- **訳:** 訳の辞書があれば、候補やタグに代表の訳を添えます(表示だけ。タグそのものやプロンプトは変えません)。複数の訳の辞書があれば、先に登録したものを優先します。
- **自動タグの訳:** 自動タイトル・タグの「タグの言語」がローカライズのとき、ONNX タガーの英語のタグの訳には辞書の代表の訳を使い、辞書に無いタグだけを LLM・VLM に頼みます。100 文字を超える訳は使いません([auto-tags.md](auto-tags.md))。

辞書を無効にすると、その辞書は候補にも訳にも使いません。削除すると、取り込んだ中身も消えます。
